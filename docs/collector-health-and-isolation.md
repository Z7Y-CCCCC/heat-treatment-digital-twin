# 采集状态与精简运行中心

## 操作入口

- **后台 → 系统设置 → 采集状态**：自动显示采集进程、心跳、正常/异常设备、帧传递耗时和最近采样。展开“设备状态”查看单台读取耗时及故障。
- 现场采集与模拟演示仍是明确的数据来源选择，切换需要确认。**掉线不会自动切成模拟数据**。
- 工厂采集开关仍独立于地图显示开关。配置以后台设备管理、点位映射为准；小窗口不再维护第二套配置。
- **采集运行中心**：仅保留概览、点位、日志及服务启停/重启；后台配置、诊断导出收进“更多”。关闭窗口不停止后台采集。
- 开机采集仍需 Windows 服务实际安装并运行；检测到应用托管的采集进程，不等于开机服务已经安装。

## 隔离与延迟

1. 不同 PLC 端点/Unit ID/采样周期的任务异步独立运行，连接和读取各有截止时间、指数退避。TCP 握手不等于读数成功，不会把“不停接受连接、却一直不回数据”的设备误标在线，也不因此清零失败退避。一个端点不回应，不等待它再读取其他端点。
2. Modbus 相邻/重叠地址按区合并，不跨未配置的地址空洞；每块最多 120 寄存器或 2,000 位，保留字序、字节序和位寻址。
3. 合法的 Modbus 地址/功能异常响应按块拆分，坏点单独置空并冷却 10 秒再探测；传输超时仍按端点重连。拆分探测有预算，不无限扩散请求。
4. S7 的“部分点质量差”和 OPC UA 的单个坏节点，不再丢弃同批正常值。混合质量设备保留正常字段，故障由逐点质量和设备降级状态表达。
5. 保存设备/点位后，按工厂合并刷新请求；只重建配置变化的采集任务，未变化任务保留连接、定时器和采集进程 PID。删除设备同时清理过期快照和待发送数据，避免长期操作形成幽灵设备。
6. 来源切换通过窄接口和期望模式校验；不重启整个采集进程，不影响其他工厂。重复保存相同模式不会重连现有任务。

这是软实时采集，不承诺任意硬件/网络下的固定延迟。实际周期受 PLC 响应、点数、网络及机器负载影响；超出周期的请求不叠加积压。同一物理 PLC 本身断电时，共用它的设备自然都会受影响，其他端点继续采集。

## 真实健康状态

- 进程是否存活、心跳是否及时、设备/点位是否正常分别判断；“进程运行中”不能冒充“所有设备正常”。
- 采集进程无响应仍由已有独立看门狗恢复；管理 API 与大屏渲染不随采集子进程退出。
- `GET /api/collector/status`：当前工厂的实际状态，要求采集状态/点位监视等页面授权。
- `PUT /api/collector/mode`：只允许来源和期望来源，要求该页编辑权限和 CSRF，不能夹带 PLC 配置字段。
- 原有 `/api/health` 增加无凭据汇总，原生窗口与网页显示同一份健康判定；Unity 是否在线不影响采集进程健康判断。
- “帧传递耗时”是采样帧时间到管理进程收到它的时间，不是 PLC 读取耗时；后者在设备明细单独显示。页面约 2 秒更新，不改变 PLC 配置的采样周期。

## 已执行验证

使用隔离数据库、真实回环 Modbus TCP、独立采集子进程和 WebSocket；未操作现场 PLC、未安装/验证安装包，也未重启操作员的后台。

- 200 个连续寄存器合并读取；同时加入永不响应的 Unit ID、非法地址、同 PLC 正常设备。
- 坏端点/坏地址并存时正常流继续；断开另一台正常 PLC 后，其余 PLC 仍继续；恢复后自动重连。
- 后台改点位保留未变连接及 PID；删除设备清理旧快照。
- 本机一轮 100ms 配置下：正常采样间隔 P95 **102ms**，采样到 WebSocket P95 **13ms**。这是回环测试结果，不是现场保证值。
- 额外覆盖 S7 部分坏质量、OPC UA 坏节点、来源 CAS、权限/CSRF、网页状态掉线与自动恢复。
- 原生运行中心为系统 .NET Framework / WinForms，小于 200 KiB，无 Electron、无浏览器内核。一次 30 秒窗口测试私有内存约 40 MiB，平均 CPU 约 0.08%（该测试机器）。

复现（项目根目录）：

```powershell
node backend/scripts/collector-isolation-test.cjs
npm --prefix backend test
npm --prefix frontend test
node desktop/scripts/native-collector-center-test.cjs
```

设置 Playwright 模块/Chromium 路径后执行 `node tools/collector-health-ui-test.cjs` 可复现网页操作。原生 `--smoke-test OUTPUT` 仅生成隔离的界面测试证据，不执行服务启停。
