# 可复用数据集与组件绑定

## 使用

1. **系统设置 → 数据连接与备份 → 外部数据源 → 连接**：登记服务地址和认证；登录取 Token 配置也在这里，不在组件中保存凭据。
2. **数据集**：选择连接，配置接口或数据表；需要跟随设备时，设置请求参数或记录匹配。
3. **字段映射**：读取真实字段，选择输出名称、类型和单位；字段标识、用途、倍率和偏移在每行的 `···` 中。
4. **数据预览**：输入对象 ID，核对记录与读取时间，再保存。
5. **大屏设计器 → 组件 → 数据来源 → 可复用数据集**：选数据集、字段和设备范围，读取预览，保存并发布。

界面采用连接/数据集切换、左侧列表和右侧编辑。配置、参数、字段、预览互相切换；字段和样例不再上下堆叠。组件只显示常用绑定项，聚合放在“更多设置”。

## 本批边界

- 工厂隔离的数据集持久化、版本冲突保护、备份/迁移设置收录；既有直接绑定仍兼容。
- HTTP GET、显式声明的只读 POST；动态路径、Query、Body、Header 和固定/当前对象参数。
- 登录接口取 Token、已有认证方式；后端缓存并受控刷新，不向组件返回凭据。
- 数据表按字段只读查询，参数化对象过滤；嵌套响应根节点、字段映射、类型、倍率/偏移、聚合。
- 数值、文本、状态、事件列表、图表和 KPI 组件；发布后使用同一运行接口读取数据。切换对象时拒绝迟到响应；缺失/异常不冒充零值。
- 原有 PLC 参数采集不改动；没有新增 Electron 依赖。

流协议仍沿用既有取样适配器，尚未升级为常驻订阅；目录中的待接入驱动仍待接入。本批没有实现数据集驱动 Unity 原生模型属性/动画，也没有验证安装包或现场 ERP/PLC。

## 验证

全部使用隔离数据库、回环接口和独立浏览器，不操作正在使用的大屏。

```powershell
node backend/scripts/data-set-test.cjs
node backend/scripts/data-source-http-regression-test.cjs
node backend/scripts/project-bundle-test.cjs
node backend/scripts/page-permissions-test.cjs
npm --prefix frontend test
npm --prefix frontend run build
node tools/data-set-workflow-ui-test.cjs
node tools/data-source-workspace-ui-test.cjs
```

浏览器脚本可用 `PLAYWRIGHT_MODULE` 指定已有 Playwright，`BROWSER_EXECUTABLE` 指定测试 Chromium。测试输出在忽略的 `output/`，不进仓库。
