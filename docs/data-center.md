# 数据中心

## 目的

将“接入和整理数据”与“制作画面”分开。一级菜单统一提供数据表目录、数据源、点位映射、点位监视和报警配置，继续复用原有采集与外部数据读取引擎，不复制连接密钥、实时值或点位。

这些子页全部位于**左侧栏「数据中心」展开菜单**，内容区不再重复放一排顶部切换按钮。页面顶部的“接入数据 → 整理数据表 → 设计器选取”只是使用流程说明，不是另一套导航。

## 初次使用

1. **接入数据**：设备管理中已配置的资料与只读采集点位会自动收录。接口、数据库、文件等外部渠道在左侧「数据中心 → 数据源」中配置。
2. **整理数据表**：在左侧「数据中心 → 数据表」的「新建 / 管理外部数据表」中选数据源、读取数据库表或接口字段，设置中文名称、类型与单位。多设备结果使用「参数与匹配」将设备标识关联到当前设备；多部件结果关联到当前部件。
3. **浏览核对**：选择一张表后，切换「数据浏览」，按对象、数据项查看真实记录；「字段目录」保留名称、分类和单个样本的整理功能。接口路径或转换规则留在接入配置里，不要求每个画面组件重复处理。
4. **设计器选取**：在画面／悬停模板中选择已经整理好的用途分类和数据项，底层仍使用原有动态绑定。

## 点位映射的排版

点位映射始终使用一条点位一行的紧凑表格，不拆成卡片或多行。全部设备模式的设备列显示简名，完整层级保留在悬停标题与可搜索选择菜单中；用途和类型选中后显示短名，展开菜单仍提供完整中文说明。名称、地址与报警说明的剩余空间优先保留，周期、读写和单位用紧凑列，语音和删除使用带可访问名称的小图标。

换算倍率、偏移修正和显示小数在“显示换算字段”后仍追加到同一行，不改变任何绑定或实际读数。常见窗口的默认字号无需横拖；极窄窗口、200%大字号或高级列较多时，只允许一个明确横向滚动区，保持文字字号与单行结构，不通过裁掉字段假装显示完整。工厂语音总开关只在工具条展示一次。页面正常纵向滚动，分页不变；新增点位跳到最后一页并定位到新增行，不滚动其他表格。新点位绿色边框、地址冲突、失败保存草稿及原权限保持不变。

## 分类规则

默认包含设备资料、实时采集、生产业务、报警信息、部件信息及未分类。除未分类外可新增、重命名和删除，包括默认分类。删除分类只将其数据项移到未分类，不删除连接、设备、点位、数据表或已配置的组件绑定。

分类以数据项为粒度，一张表可以同时包含不同用途的数据。例如设备点位表中的温度归实时采集，而电耗可以归自定义的能耗管理。同名字段带数据表、设备范围、类型和单位，便于辨认。

数据项编辑只修改目录中的显示名称与用途分类，不能修改实际读数、运行状态、所属车间／产线等动态结果，也不能把动态值冻结成固定文字。

点击当前行右侧的铅笔图标，显示名称与用途分类会在原单元格内变为输入框／下拉框，不再打开底部“整理数据项”表单。勾号保存、叉号取消；名称输入框支持 Enter 保存、Esc 取消，中文输入法选词期间不会触发这些快捷键。保存失败保留草稿；切换表、分类、预览设备或离开前确认未保存修改。

## 点位映射列表

每个点位固定占一行，常用字段共享表头；换算字段展开后仍在同一行，不拆成卡片。设备列只显示设备名称，完整车间／产线路径在鼠标悬停提示与设备选择菜单中查看、搜索；设备名称缺失时显示设备 ID，不回退成整条路径。语音配置和删除使用行末图标。

默认字号下，1366／1440 宽度的常用列表无需左右拖动；窄窗口、大字号或展开换算字段时，仅表格区域允许横向滚动，保持字号与单行结构，行末操作仍可访问。

## 数据源首页

左侧「数据中心 → 数据源」先显示已保存连接的数量、启用数量、最近检查通过数量与连接列表；未保存草稿、类型选项及主系统数据库不计入数量。最近检查通过不代表当前在线。

只有点击「新建数据源」才显示 28 种接入方式。类型卡片用紧凑布局，保留搜索、分类和清晰的能力状态；“可接入”与“已配置连接”是不同概念。大字号或窄窗口允许整个弹窗滚动，不裁掉选项和文字。

## 预览与读取状态

点位监视表格的「设备」列默认仅显示设备名称；鼠标悬停该单元格才显示完整车间／产线／设备路径。上方设备筛选菜单仍保留完整路径，方便区分同名设备。名称暂不可用时回退到运行帧设备名称或设备 ID，不将层级路径直接塞回表格。

- 正常：实际内部资料或当前采集记录质量正常。
- 已配置：外部数据表已整理，尚未在目录中请求接口读取；可在数据表编辑页读取预览。
- 未读取／未更新／异常：不填造一个“正常”状态，缺少值时显示 `—`。
- 已停用：保留目录和绑定，提示连接或数据表当前不可读取。
- 连接未配置：来源已移除或不匹配；保留数据表和组件绑定，先修复来源后才恢复为设计器可选项。

悬停模板中可用「＋ 添加数据行」快速增加一行：左侧标题可编辑，右侧选择真实绑定数据；字体、配色、分隔线沿用现有行，自动向下移动点击提示并增高背景，整行组合且一次撤销。

目录列表不会为了展示而自动请求所有外部接口。工厂切换、编辑权限、乐观版本冲突、未保存草稿与异步请求身份均沿用管理端约束。

### 单值预览的实际边界

当前字段目录的预览是核对样本，不是完整数据浏览：设备资料来自所选预览设备（默认第一台）；采集点位只读取该样本设备的已有运行帧；部件资料使用已有拆解模型中的一个部件样本；外部表只列字段定义与配置状态，不自动请求外部源。加载、刷新或切换预览设备时重新读取，目录不持续轮询。

### 数据浏览

入口是左侧「数据中心 → 数据表」：选用途分类和一张具体表，在该表标题右侧切换「字段目录 / 数据浏览」。这是同一张表的两种查看方式，不是新的顶部子页导航。

- **设备／部件资料**：读取当前工厂实际设备资料及每台设备有效拆解配置中的部件，而不是复制目录里的单个样本。选择数据项可对比多个对象的值，支持对象筛选、搜索与分页。第一列显示对象简名，完整所属路径放在悬停提示中。
- **实时采集／连接状态**：读取已有采集引擎当前运行帧，显示数据项、实际值、更新时间和读取状态。没有运行帧、断线或过期时，不把点位配置中保存的样例当成当前值。
- **外部数据表**：复用已保存的数据源、字段与对象映射。选中表的字段目录会通过独立授权的记录接口读取第一条实际记录作为临时核对样本；数据浏览显示本次读取的完整记录窗口。目录元数据接口本身不访问外部来源，样本不写入配置、不跨行拼接。需要对象上下文的表先选择设备／部件。来源未配置、已停用、请求失败或没有记录时明确提示，不能回退成示例读数。
- **历史边界**：目前没有每个 PLC 点位的历史存储，工厂汇总快照不能冒充点位历史。只有外部表已经包含真实时间字段与返回记录时，才提供时间范围和数值趋势；趋势仅对应本次实际读取的记录，不生成中途值，也不宣称覆盖源系统的全部历史。
- **读取范围**：外部浏览遵守原数据表读取器的有界记录窗口；页面说明实际读取范围。总数和分页只统计本次读到的可浏览记录，不把源端的未知总数或当前窗口当成整库总量。

为了避免大量字段撑成超宽表，浏览采用「对象 / 数据项 / 实际值（含单位） / 更新时间 / 状态」的单行记录结构。按数据项筛选后，就能查看该项在所有对象或实际返回记录中的值。搜索不会修改字段或组件绑定，分页也不会保存当前读数；刷新使用同一个只读入口。

切换到浏览前保护未保存的字段整理草稿。离开浏览、切换工厂／数据表或请求失败时，不保留上一对象的读数冒充新结果。浏览操作不会新增点位、变更设备、写入 PLC 或把动态项转换为常量。

从默认「当前工厂」入口进入时，浏览使用目录实际返回的工厂 ID，后续读取明确携带该工厂范围，不能因为页面未手动选厂而显示空表。外部实际记录沿用原数据集读取权限：只有目录或点位监视权限不能越权读取外部记录，查看内部资料／点位的既有权限不变。

### 更新时间显示

数据表预览、字段目录和数据浏览统一显示本机时区的完整日期与时分秒，例如香港时区 `2026-11-07T07:44:16.837Z` 显示为 `2026-11-07 15:44:16`；悬停保留源原始值。普通编号和文字不自动转日期。

记录更新时间优先使用明确配置的时间字段；旧表没有配置时间角色时，兼容唯一、明确的 `updatedAt / updated_at / update_time / 更新时间` 等源字段。缺失、非法或有歧义时仍显示 `—`，不使用「本次读取」时间冒充来源更新时间。兼容识别的更新时间不自动启用历史查询，不修改原字段映射或动态绑定。
