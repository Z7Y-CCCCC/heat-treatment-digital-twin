# 数据中心

## 目的

将“接入和整理数据”与“制作画面”分开。一级菜单统一提供数据表目录、数据源、点位映射、点位监视和报警配置，继续复用原有采集与外部数据读取引擎，不复制连接密钥、实时值或点位。

这些子页全部位于**左侧栏「数据中心」展开菜单**，内容区不再重复放一排顶部切换按钮。页面顶部的“接入数据 → 整理数据表 → 设计器选取”只是使用流程说明，不是另一套导航。

## 初次使用

1. **接入数据**：设备管理中已配置的资料与只读采集点位会自动收录。接口、数据库、文件等外部渠道在左侧「数据中心 → 数据源」中配置。
2. **整理数据表**：在左侧「数据中心 → 数据表」的「新建 / 管理外部数据表」中选数据源、读取数据库表或接口字段，设置中文名称、类型与单位。多设备结果使用「参数与匹配」将设备标识关联到当前设备；多部件结果关联到当前部件。
3. **预览核对**：读取预览确认真实值、字段和对象映射。需要填写接口路径或转换规则的工作留在这里，不要求每个画面组件重复处理。
4. **设计器选取**：在画面／悬停模板中选择已经整理好的用途分类和数据项，底层仍使用原有动态绑定。

## 分类规则

默认包含设备资料、实时采集、生产业务、报警信息、部件信息及未分类。除未分类外可新增、重命名和删除，包括默认分类。删除分类只将其数据项移到未分类，不删除连接、设备、点位、数据表或已配置的组件绑定。

分类以数据项为粒度，一张表可以同时包含不同用途的数据。例如设备点位表中的温度归实时采集，而电耗可以归自定义的能耗管理。同名字段带数据表、设备范围、类型和单位，便于辨认。

数据项编辑只修改目录中的显示名称与用途分类，不能修改实际读数、运行状态、所属车间／产线等动态结果，也不能把动态值冻结成固定文字。

## 预览与读取状态

- 正常：实际内部资料或当前采集记录质量正常。
- 已配置：外部数据表已整理，尚未在目录中请求接口读取；可在数据表编辑页读取预览。
- 未读取／未更新／异常：不填造一个“正常”状态，缺少值时显示 `—`。
- 已停用：保留目录和绑定，提示连接或数据表当前不可读取。
- 连接未配置：来源已移除或不匹配；保留数据表和组件绑定，先修复来源后才恢复为设计器可选项。

悬停模板中可用「＋ 添加数据行」快速增加一行：左侧标题可编辑，右侧选择真实绑定数据；字体、配色、分隔线沿用现有行，自动向下移动点击提示并增高背景，整行组合且一次撤销。

目录列表不会为了展示而自动请求所有外部接口。工厂切换、编辑权限、乐观版本冲突、未保存草稿与异步请求身份均沿用管理端约束。

## 参考核对

2026-11-06 实际查阅的公开一手材料：

- [CIMPro 孪大师 piadmin 数据接入操作手册](https://forum.picimos.com/thread/72)：教程明确分为数据源、数据表、类型结构／对象属性以及编辑器使用。编辑器从已配置的数据表下拉选取，映射对象属性到数据表字段。
- [阿里云 Quick BI 字段配置](https://help.aliyun.com/zh/quick-bi/user-guide/detail-processing/)：数据集层提供字段显示名、类型、展示格式、分类文件夹及字段移动管理。

本项目借鉴的是分层与可复用字段目录，不宣称支持上述产品的所有数据源、脚本过滤器或复杂建模功能。仍未实际接入的生产业务数据不会伪造出占位读数。
