# ERP / MES / VMS 模拟接口接入练习

这三个接口是独立运行在本机的**模拟外部系统**，不会读取或修改现有大屏数据库，也不连接 PLC。它们没有自动加入大屏；由使用者在「数据中心」手动接入。

这里的 **VMS 是工厂销售管理系统**，提供销售订单、客户、销售金额与回款数据。

## 1. 启动模拟接口

在项目目录运行：

```powershell
node "C:/Users/27323/OneDrive/Desktop/大屏/tools/mock-external-systems.cjs"
```

或者运行启动脚本：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "C:/Users/27323/OneDrive/Desktop/大屏/tools/启动模拟ERP-MES-VMS.ps1"
```

无需安装额外 npm 依赖；使用本机 Node.js 22 或更新版本。保持启动窗口开启，在该窗口按 `Ctrl+C` 停止。

打开工作台：[http://127.0.0.1:19090](http://127.0.0.1:19090)。这里可以复制根地址、接口路径与结果根节点，也能查看当前模拟数值和字段单位。

如果提示端口已占用，可以改用：

```powershell
node "C:/Users/27323/OneDrive/Desktop/大屏/tools/mock-external-systems.cjs" --port 19091
```

下文的 `19090` 也相应改成 `19091`。服务只监听 `127.0.0.1`，因此应在**运行大屏后台的同一台电脑**启动；不能把另一台电脑的 `127.0.0.1` 当成这台电脑。

## 2. 在数据中心新建三个数据源

入口：**数据中心 → 数据源 → 新建数据源 → HTTP / REST**。

| 配置项 | 模拟 ERP | 模拟 MES | 模拟 VMS（销售管理） |
|---|---|---|---|
| 数据源名称 | 模拟 ERP | 模拟 MES | 模拟 VMS 销售管理 |
| API 根地址 | `http://127.0.0.1:19090/erp` | `http://127.0.0.1:19090/mes` | `http://127.0.0.1:19090/vms` |
| 健康检查地址 | `/health` | `/health` | `/health` |
| 响应格式 | JSON | JSON | JSON |
| 认证方式 | 无认证 | 无认证 | 无认证 |
| 启用此连接 | 勾选 | 勾选 | 勾选 |

点击测试连接，应显示检查通过；再保存。用户名、密码、Token 都不用填写。

**根地址不要填写到具体数据接口**。例如根地址填 `/mes`，不是 `/mes/production`；具体接口在数据表中选择。

## 3. 新建可复用的数据表

入口：**数据中心 → 数据表 → 新建数据表**。

所有模拟表都使用：请求方式 `GET`、结果根节点 **`data.rows`**。界面的「刷新间隔」单位为**秒**，请填 **`3`**；内部对应 3000 毫秒，不要在界面填 3000。模拟值每 3 秒按固定演示规则变化，周期结束后会重新循环，并非正式生产累计数。

| 数据表名称 | 数据源连接 | 接口路径 | 推荐用途/分类 | 推荐字段 |
|---|---|---|---|---|
| 模拟生产订单 | 模拟 ERP | `/orders` | 生产业务 | 设备名称、订单号、产品、计划数量、已完成数量、订单状态 |
| 模拟物料库存 | 模拟 ERP | `/inventory` | 库存物流（可自建分类） | 物料名称、库存数量、已占用数量、可用数量 |
| 模拟生产进度 | 模拟 MES | `/production` | 生产业务 | 设备名称、已完成数量、合格率、生产进度 |
| 模拟设备状态 | 模拟 MES | `/devices` | 实时采集 | 设备名称、连接正常、运行状态、温度、推料到位、退回到位 |
| 模拟销售订单 | 模拟 VMS 销售管理 | `/sales-orders` | 销售业务（可自建分类） | 客户、销售订单号、销售数量、订单金额、已回款金额、待回款金额 |
| 模拟销售回款汇总 | 模拟 VMS 销售管理 | `/sales-summary` | 销售业务（可自建分类） | 客户、目标金额、已销售金额、已回款金额、回款率 |

### 最简单的第一次练习：模拟生产进度

1. 数据表名称填「模拟生产进度」，数据源选「模拟 MES」。
2. 接口路径填 `/production`，请求方式保留 `GET`。
3. 结果根节点填 **`data.rows`**。
4. 「参数与匹配」先不要添加参数，**关闭「记录匹配」开关（按当前对象匹配记录）**，查看全部 4 条模拟记录。
5. 打开「字段映射」，点击「解析字段」。选需要的字段，再点「添加到映射」。
6. 中文名称可以改；来源字段保持下面的真实路径。默认那一行 `value` 若不用，应删除或改为真实字段，不能留一个接口中没有的字段。

| 中文名称 | 来源字段 | 类型 | 单位 | 字段用途（可选） |
|---|---|---|---|---|
| 设备名称 | `deviceName` | 文本 | 留空 | 分类 |
| 已完成数量 | `completedQty` | 数值 | 件 | 主数值 |
| 合格率 | `qualifiedRate` | 数值 | % | 普通字段 |
| 生产进度 | `progress` | 数值 | % | 普通字段 |
| 更新时间 | `updatedAt` | 文本 | 留空 | 普通字段 |

7. 点击「读取预览」，应看到 4 台模拟设备的实际记录。稍等 3 秒再读取，已完成数量、合格率等会变化。
8. 保存数据表。按软件现有分类入口放到「生产业务」。
9. 到大屏设计器选择这张表及对应中文字段，不再手工填写接口路径。例如数字卡片选「已完成数量」，选择「求和」可显示全部设备总数；列表/图表选择设备名称作为分类。

**先练习全表数据，再考虑按设备匹配。** `DEMO-FURNACE-03` 等是模拟对象 ID，通常不等于现有软件设备 ID。直接开启「当前设备匹配」可能得不到记录，并不是接口连接失败。

### 进阶：练习按一个模拟对象匹配

接口支持可选 Query 参数 `deviceId`。例如：

```text
http://127.0.0.1:19090/mes/production?deviceId=DEMO-FURNACE-03
```

在数据表「参数与匹配 → 请求参数」新增：参数名 `deviceId`、位置 `Query`、来源 `固定值`、值 `DEMO-FURNACE-03`，即可只读取一台模拟设备。无需再开启对象匹配。

也可以使用软件已有的全局参数并在设计器中选择模拟 ID；只有将模拟 ID 与真实设备 ID 建立清晰映射后，才应使用「当前设备」参数。脚本不会擅自把模拟数据替换成现场设备数据。

## 接口结构与边界

- 6 个数据接口默认各有 4 条记录；跨 ERP / MES / VMS 共用 `deviceId`，ERP / MES / VMS 销售订单共用 `orderNo`；ERP 与 VMS 还共用 `salesOrderNo`、`customerId`。
- 每个响应含 `simulated: true`、`updatedAt`、`total`、`data.rows` 与字段说明 `fields`。数据浏览使用 `data.rows`，**不是** `fields`。
- 库存、温度、生产进度、销售回款随时间变化；数字保持数值类型、开关状态保持布尔类型。
- MES 的推料/退回状态只是模拟开关量，不会触发真实设备。它们用于检查读取、显示与条件配置，不是现场运行凭据。
- 只接受 `GET` 读取；不提供控制、写入、删除或重置接口。所有不存在的接口返回 `404`。
- 不保存历史记录、真实业务资料或凭据；停止模拟服务后接口不可用。
