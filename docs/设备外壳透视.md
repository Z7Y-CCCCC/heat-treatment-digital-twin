# 设备外壳透视

目的：观察内部机构的运动，同时保留装配关系，而不是仅显示活动件。

## 显示分类

- 透明：实际遮挡内部观察的外层板件，如外罩、炉衬、门蒙板与密封、检修盖及随附紧固装饰件。CAD 多层蒙板采用低不透明度，避免多层叠加重新形成实墙。
- 实体工作机构：叶轮、辊道、提升链、滑架、驱动电机、隔热门、搅拌机构等。是否当前正在运行不改变此分类。
- 实体静态参照：底座、导轨、支架、必要管路、仪表等，不因为它们静止就一起透明。
- 未明确指定为外层板件的网格默认保持实体，不做“所有非活动件透明”的反选。

已知 CAD 装配组按精确节点语义划分。若内部机构或静态参照位于外罩的子层级，以最近的功能节点为准，不继承外罩透明。自定义模型可沿用已配置的 inspection.shell。

## 交互

设备的实体/透视视角中，顶部状态条旁固定显示 58px 图标；不跟随旋转、平移或缩放。实体立方体代表外壳显示，虚线立方体与齿轮代表外壳透明，按钮不显示文字。

仅修改本机渲染状态；不写入 PLC、不启动演示动作、不暂停已绑定的实际动作。切换设备或退出设备视角恢复外壳，内部原材质、动画位姿与静态参照不被重置。

验证：`node tools/shell-cover-coverage-test.cjs`、`node tools/native-shell-transparency-checks.cjs`、`node tools/shell-transparency-ui-test.cjs`。
