# 回火炉默认拆解与模型悬停预览

## 变更

- `cad_tempering_furnace_091300` 补齐 19 个可编辑总成，覆盖原 CAD 全部 67 个网格：底座、炉壳、内衬、加热元件、接线端、炉门、导轨、提升链条、门驱动、辊道、叶轮、循环风机、风机罩、排气罩、电气仪表、工艺仪表、管路、阀门、后检修盖。
- 原始 CAD GLB 不变，SHA-256 为 `a0f151f1cffbe9ce23c12f6db9d4a8a7ab3a42f18c21d23b6a2f5b7ed6565dd9`。
- 旧库中同一原始文件的空拆解配置在读取时补默认值，不直接改库。已有非空拆解、外壳引用、实例覆盖、停用设置、名称和 PLC 绑定保持不变；替换上传的其他模型不套用节点。用户保存后按正常模型布局接口持久化，支持版本冲突检查。
- 修正动作导出层级：回火炉叶轮、风机传动轴和辊筒放回对应 CAD 总成，重新生成此模型的便携动作包。4 个原有动作保留，Unity 拆解不再遗漏活动零件。
- 设备管理的固定设备、辅助设备模型栏支持鼠标悬停或键盘聚焦预览，优先显示设备的 `model_file` 覆盖文件。移开、滚动、切页或 Escape 关闭。
- 延迟 180 ms 才加载；单次静态渲染后立即释放模型及 WebGL 上下文，无常驻动画循环；最多缓存 12 张 CPU 图片。多行同模型复用图片，失效或缺失文件显示简短状态，不用其他模型冒充。
