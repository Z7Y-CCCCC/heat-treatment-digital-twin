# CAD 设备的动作预览

入口：模型库 → 动作动画 → 部件动作，选择对应 CAD 模型，再点设备动作或下方节点的“预览”。预览留在当前页，支持暂停、重播、速度、进度拖动、复位、内部透视和停止预览。

| 模型 | 内置动作 |
| --- | --- |
| 料车 10.13.00 | 往返行走、推料伸退、承料辊转动 |
| 升降备料台 11.14.00 | 上升回位、下降回位、承料辊转动 |
| 固定备料台 11.22.00 | 承料辊滚动；框架固定，不添加升降动作 |
| 风冷台 11.58.00HT | 门关闭打开、双风机运转、承料辊转动 |
| 清洗机 17.07.00 | 门开启关闭、泵轴运转、喷淋、注水、排水、吹扫 |
| 水冷槽 47.10.00 | 门开启关闭、承料架下降入水、升起沥水、搅拌、注水、排水 |
| 600普通多用炉 08.20.00 | 前室门、隔热门、承料架下降/升起、热室循环、淬火搅拌、热室辊道、冷热室内移料、加热循环 |

共 31 项。辊筒上的青色短线为旋转参考标记。水位、喷淋、空气流动、转速、加热发光及动作时长是演示参数，未映射现场信号，不写入 PLC；这些动作没有保存为虚构的 PLC 点位绑定。原有手动点位绑定列表及编辑索引保留。

导入 GLB 的字节、节点和既有拆解配置不变。`CadMotionRig` 只在独立预览实例内按连通几何临时分离辊筒、轴端和叶片并建立转轴；机架、轴承座、外壳和电机定子不随转子旋转。剪叉杆保持长度，通过角度、平台位置、滑块及液压杆联动演示升降；备料台演示高度相对原始位姿为 ±0.24 m，未标为现场极限行程。水冷槽承料架演示下降 1.05 m。

停止预览或切换模型释放临时几何、材质与渲染器，并回到原模型。此版本仅提供后台模型动作演示；现场实时联动和设备间工步联锁需另外配置及验收。

600 多用炉保留提供的 8.68 MB 原始 GLB（243 节点、161148 三角面），拆解为 35 组，覆盖 73 个同级总成/参考件。仅分离八个热室叶片及轮毂、转轴，循环罩固定；两组淬火叶片各自绕轴旋转，七根热室辊筒绕 X 轴旋转。隔热门演示行程 0.85 m，前门 0.90 m，承料架下降 1.05 m。行程、转速和时序仍需现场确认。

选入产线联动后，流程包含开隔门、移入热室、关隔门、加热循环、开隔门、返回前室、关隔门、下降淬火、升起沥液和料车取料。工件先回到前室，再随承料架下降；热处理和淬火时中间隔门均关闭。

验证入口：`frontend/tests/cad-motion.test.mjs` 检查实际 GLB 的动作、固定外壳、进度定位、原位复位和静态外形保持；`cad-inspection.test.mjs` 检查原拆解配置。`tools/multipurpose-600-ui-test.cjs` 在独立数据库中核验入库文件哈希、35 组拆解、九项动作及完整料车/炉内/淬火联动，且不写入设备和 PLC 配置。
