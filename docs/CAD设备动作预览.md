# CAD 设备的动作预览

入口：模型库 → 动作动画 → 部件动作，选择对应 CAD 模型，再点设备动作或下方节点的“预览”。预览留在当前页，支持暂停、重播、速度、进度拖动、复位、内部透视和停止预览。

| 模型 | 内置动作 |
| --- | --- |
| 回火炉 09.13.00 | 炉门升降、循环风机、炉内辊道、回火加热与热风循环 |
| 料车 10.13.00 | 往返行走、推料伸退、推拉钩脱开/勾合、承料辊转动 |
| 升降备料台 11.14.00 | 上升回位、下降回位、承料辊转动 |
| 固定备料台 11.22.00 | 承料辊滚动；框架固定，不添加升降动作 |
| 风冷台 11.58.00HT | 门关闭打开、双风机运转、承料辊转动 |
| 清洗机 17.07.00 | 门开启关闭、泵轴运转、喷淋、料盘下降浸洗、料盘升起出水、吹扫；下部中央及左右水槽常驻满水，不演示注排水 |
| 水冷槽 47.10.00 | 门开启关闭、承料架下降入水、升起沥水、搅拌、注水、排水 |
| 600普通多用炉 08.20.00 | 完整工艺循环、前室门、隔热门、承料架下降/升起、热室循环、淬火搅拌、热室辊道、冷热室内移料、加热循环 |

共 37 项。辊筒上的青色短线为旋转参考标记。水位、喷淋、空气流动、转速、加热发光及动作时长是演示参数，未映射现场信号，不写入 PLC；这些动作没有保存为虚构的 PLC 点位绑定。原有手动点位绑定列表及编辑索引保留。

`CadMotionRig` 在独立预览实例内按连通几何临时分离辊筒、轴端和叶片并建立转轴；机架、轴承座、外壳和电机定子不随转子旋转。料车中央新增推拉钩的派生 GLB，原始源模型保留；安装结构、来源和重建步骤见 [料车推拉钩试装](料车推拉钩试装.md)。剪叉杆保持长度，通过角度、平台位置、滑块及液压杆联动演示升降；升降备料台的辊筒及其转轴隶属于升降台面，上升、下降和独立转动时均保持与料台的相对位置，不留在模型根节点悬空。备料台演示高度相对基准位姿为 ±0.24 m，未标为现场极限行程。统一送料高度后的水冷槽承料架演示下降 0.85 m，多用炉下降 0.80 m。

停止预览或切换模型释放临时几何、材质与渲染器，并回到原模型。上述动作同时导出为 Unity 可读取的动作包，现场点位绑定见 [设备动画实时联动](device-animation-live.md)；现场工步联锁仍需另外配置及验收。

清洗机 17.07.00 的中央浸洗区和左右水槽水面固定在模型 Y=1.20 m，预览、复位及运行期间都保留水体。料盘和原有承料辊台同步演示下降 0.80 m，物料顶部完全低于水面；上升动作返回进出料高度。设备联动依次执行送料、退链、关门、下降浸没、清洗、升起、吹扫和出料，不再插入注水或排水工步。升降行程为根据现有模型空间设置的演示参数，现场接入时按实际反馈标定。

回火炉原交付 GLB 保留，模型库采用统一送料高度的派生版本（见 [设备统一送料高度](设备统一送料高度.md)）：八片炉内叶轮和内转轴绕 Y 轴旋转，顶置横轴/竖轴分别绕各自中心转动；七根炉内辊筒绕 X 轴旋转，电机壳、罩壳、导轨及十四个轴承座固定。炉门和滑架沿 Y 轴演示上升 0.90 m，加热仅改变独立加热管材质，不让共用黑色材质的炉门一起发光。产线模拟在关门后执行回火加热、热风循环保温；辊筒在送料和取料阶段转动，加热期间停止。实机行程、温度和转速需按现场反馈配置。

600 多用炉保留提供的 8.68 MB 原始 GLB（243 节点、161148 三角面），拆解为 35 组，覆盖 73 个同级总成/参考件。仅分离八个热室叶片及轮毂、转轴，循环罩固定；两组淬火叶片各自绕轴旋转，七根热室辊筒绕 X 轴旋转。隔热门演示行程 0.85 m，前门 0.90 m，承料架下降 0.80 m。行程、转速和时序仍需现场确认。

选入产线联动后，流程包含开隔门、移入热室、关隔门、加热循环、开隔门、返回前室、关隔门、下降淬火、升起沥液和料车取料。工件先回到前室，再随承料架下降；热处理和淬火时中间隔门均关闭。

多用炉新增“完整工艺循环”本页预览：前室送料 → 打开中门 → 送入后室 → 关闭中门加工 → 打开中门返回前室 → 关闭中门 → 料架下降油淬 → 升回前室 → 沥油 → 开外门拉出料盘。预览标题下显示当前工步，支持暂停和拖动进度；前后室视图只在选择动作时定位一次，切换工步不重置镜头。它与设备联动使用同一工步时序，回程辊道反向，沥油期间外门保持关闭；没有选料车时，单机工艺预览也保留炉内工件。完整循环按原时长导出到共享动作包，不截成 5 秒短片。

600 多用炉沥油采用琥珀棕色有光泽的油珠：先在承料架/工件下缘形成油珠和细颈，再拉长、断开并回落到实际油槽位置；滴落数量随演示时间减少，入槽后隐藏，不做蓝色水花。承料架未离开液面时不产生悬空滴落。此为油液外观示意，不表示实测黏度或排油速率；水冷槽仍使用原来的蓝色水滴。

验证入口：`frontend/tests/cad-motion.test.mjs` 检查实际 GLB 的动作、固定外壳、进度定位、原位复位和静态外形保持；`cad-inspection.test.mjs` 检查原拆解配置。`tools/multipurpose-600-ui-test.cjs` 在独立数据库中核验入库文件哈希、35 组拆解、九项动作及完整料车/炉内/淬火联动，且不写入设备和 PLC 配置。
