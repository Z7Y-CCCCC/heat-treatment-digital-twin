# 朋友下载与动作演示

## 直接使用 Windows 软件

到原仓库的 [Releases](https://github.com/Z7Y-CCCCC/heat-treatment-digital-twin/releases) 下载 **CAD 动作演示 2.3.1** 中的 Windows x64 安装包及校验文件。下载者需要有此私有仓库的访问权限。不要使用旧安装包，也不要把 GitHub 的 Source code ZIP 当成已编译软件。

安装后从桌面入口启动，首次运行按软件提示设置自己的后台账号。后台进入「模型库 → 模型管理」选择模型，再进入「动作动画 → 部件动作」预览。新 CAD 设备的演示动作由随包代码提供，不需要先绑定 PLC。

「设备联动」使用所选产线的真实设备实例。新电脑请先在工厂、车间、产线中添加设备并选择对应模型，随后在设备联动中勾选设备；单纯拥有模型资产不会自动创建产线设备。不想配置产线时仍可直接体验部件动作和拆解。

安装包使用初始模板，不包含开发电脑的账号、现场数据库、PLC 连接凭据或运行历史。已有电脑的数据按原有升级策略保留。演示动画不会向 PLC 下发指令。

## 下载源码继续开发

本次功能分支为 `codex/cad-animations-delivery`。PR 合入 main 前，下载 main 还不包含本次动作代码。通过 Git 下载：

```powershell
git lfs install
git clone --branch codex/cad-animations-delivery https://github.com/Z7Y-CCCCC/heat-treatment-digital-twin.git
cd heat-treatment-digital-twin
git lfs pull origin
node tools/model-assets.cjs --check
```

模型目录中的 GLB 必须是实际模型内容，不能只是约 130 字节的 LFS 指针。无需从开发者桌面路径复制模型；库注册、拆解配置和演示动作均在仓库中。

源码首次构建请按 [开发交接与仓库约定](开发交接与仓库约定.md) 安装所需版本的 Node.js、.NET、Unity 及依赖，随后执行 `生成安装包.ps1 -StarterTemplate -NoPause`。构建完成后，`启动大屏.cmd` 会在每次启动时编译当前目录的前端，保持正常默认首页。该入口不是首次下载源码的环境安装器。

- 回火炉、料车、升降备料台、固定备料台、风冷台、清洗机、水冷槽及 600 普通多用炉的 GLB 和库注册。

- 自选产线、设备实例、顺序和布置方式的设备联动预览，包含进出料及适用设备的工艺过程。
