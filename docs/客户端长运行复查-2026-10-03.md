# 客户端长运行遗漏修复（2026-10-03）

本轮在现有资源修复与原生/前端审计基础上继续检查前端、Unity WebSocket 和 Electron 生命周期。发现并修复下表八类具体遗漏。没有连接原服务器、实体 PLC 或业务数据库，没有降低画质、模型精度、帧率或采集频率，没有提交或推送代码。原生全链与重新构建候选包的结果由本轮总报告汇总；本文的单元/回环测试不能代替 72 小时验收。

## 具体缺陷与修复

| 缺陷与触发方式 | 修复与证据 |
| --- | --- |
| 配置请求短暂失败时，`factoryConfig.loadConfig()` 将现场配置覆盖为 20 台 `Furnace_01` 等虚构设备；并发请求没有版本控制，坏结构能部分改写配置。 | 首次失败保持空状态，后续失败保留最后完整配置；10 秒请求 deadline；取消旧读取，仅接受最新请求；先验证结构再整体更新。新增配置回归初次运行 4/4 失败，修后 4/4 通过。 |
| Overlay 只初次注册设备，重连/普通配置事件后不同步设备集合；HUD 删除设备只清公开 map，私有 `lastSeenMap` 保留；晚到旧消息会重新插入已删除设备。 | `DataStore.syncDevices()` 同步权威设备集合，同时清理状态、数据、最后见到时间和选择；接到 Overlay/HUD 的正常配置同步；已同步后拒绝集合之外的晚到帧和 PLC 状态；保留仍有效设备的实时数据，包含车间未分配设备。200 次设备替换与真实 Overlay SFC setup/lifecycle 回归通过。 |
| TCP 已连接但 WebSocket HTTP 升级一直不返回时，浏览器/Unity 长期停在 CONNECTING，不能发起新尝试。 | 浏览器连接建立与 Unity connect/hello 各有 15 秒 deadline，失败后沿原重连路径恢复；旧 socket 回调被移除，timeout 不取消整个 Unity 客户端 lifetime。原生使用真实回环 TCP 不答升级夹具验证超时；既有 overflow/reconnect/resync 回环测试仍通过。 |
| 地图摘要每 5 秒、地图值每 15 秒继续发起读取；响应卡住时 pending fetch 不断增加，卸载后无请求取消。HUD 配置读取也可能永远占据 syncing。 | 统一 `createJsonPollingScope()` 按资源合并并发读取，deadline 覆盖响应体，卸载取消全部请求和 timer。200 次读取合并为一条 transport；不同资源独立；超时后可再次读取；卸载禁止后续读取，3/3 回归通过。 |
| 地图/HUD 挂载流程 await 配置期间卸载；旧 mounted continuation 恢复后仍创建轮询和事件监听。 | 两页 await 后检查 disposed。测试执行真实编译 SFC mounted→unmount→晚到响应，修前地图重新创建 2 个 interval、HUD 重新创建 1 个 interval，两条都失败；修后 2/2 通过，interval 和相关 listener 都为 0。 |
| HUD 模型构建只有 cancelled 标志，挂起的 GLTF 下载仍然留存；解析结果晚到时，已卸载页面不能回收其几何/材质/纹理。 | 构建器接收 AbortSignal；每个资产用独立 Three LoadingManager 取消请求；默认 30 秒模型 deadline 与原生默认一致；晚到结果释放资源。真实 Three loader 对挂起本地 HTTP 请求的取消会关闭 socket；几何/材质/纹理晚到时各 dispose 一次；取消的构建不发布场景，4/4 回归通过。 |
| AdminPanel 单模型和场景编排预览使用 `ModelFactory` 全局 URL 缓存；失败 Promise 永久驻留，模型版本增多时缓存无界。 | 失败 Promise 从缓存移除以便同 URL 重试；限制 32 项 LRU。淘汰仅删除缓存引用，不 dispose 活跃 clone 共享的几何/材质/纹理。200 个 URL 修订、失败重试与近期模型复用回归 3/3 通过。 |
| Electron 设置窗口每次重建向共享 session 增加 will-download listener，关闭窗口没有解除，旧闭包又指向全局新 mainWindow，重复弹出保存框；旧保存对话框晚返回还能 resume 旧下载。 | 下载闭包固定原窗口，窗口 closed 时解除共享 session 监听，旧窗口关闭后取消晚返回下载。新增 2 条回归初次运行均失败，修后通过；连续重建 25 次每次只有 1 个 listener，关闭后为 0。 |
