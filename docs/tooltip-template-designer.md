# 悬停提示模板

入口：后台「组件配置 → 大屏设计器 → 悬停提示」。它是提示卡的小画布编辑模式，不是新增三维视角，也不占大屏固定位置。

## 编辑与发布

1. 选择「设备提示」或「部件提示」，默认卡片已拆为独立背景区域、文字、数值与分隔线。
2. 从卡片或「内部图层」选择元素。按住 Ctrl 点击可多选，再点已选元素可取消；macOS 可用 Command，Shift 点击仍支持追加。按住已选元素拖动时，所有未锁定的选中元素一起移动；锁定元素和整卡背景保持原位。画面布局画布也使用同样的 Ctrl 多选操作。支持右下角缩放、位置尺寸输入、复制、锁定、组合及解组。
   提示背景与模板尺寸联动：右侧改宽高、拖背景右下角，或拖画布底边的高度手柄，都会同步改变画布和背景，不需要再手动贴合虚线框。背景始终锚定画布原点；其他文字、数值与独立区域不会跟着缩放或移动。一次拖动对应一次撤销。复制模板保留关联，复制背景元素不会成为新的主背景。
3. 在右侧分别编辑内容、样式和数据来源。文字支持 `{value}`、`{unit}`、大屏参数、状态值到文字的映射及空值提示。
   标题、字段标签、真正固定的提示文案可直接编辑。数据状态、名称、车间／产线归属、实时参数，以及随部件／阶段变化的说明和提示，必须保留数据绑定，不能转换为固定文案。内容页显示来源与只读的「当前显示」；显示格式必须保留 `{value}`，无占位符的常量会被拒绝，连接状态和关联信息也不会应用任意文字映射。要修改部件的源说明，应编辑对应设备实例资料或共享模型资料，不在共用提示模板里冻结当前部件的说明。
4. 选择实际设备／部件检查预览；该选择不保存为模板的固定设备绑定。
5. 在「视角引用」选择继承默认、指定模板或关闭。工厂／车间／产线共享设备提示；设备实体／透视／拆解／部件详情共享部件提示。
6. 「保存草稿」只保存；「保存并发布」同步到运行端。修改、撤销、重做、导入导出、数据重绑定及历史版本恢复都包含提示模板。

主画布中尚未选择大屏参数的筛选组件、尚未选择数据库连接的业务摘要，可以与悬停模板一起保存为未完成草稿。保存后会列出待配置项，点击「定位组件」进入对应画布与属性；发布前必须补全这些配置，或自行删除不需要的组件。已选择但失效的参数／连接、PLC 写入意图及其他非法配置仍会阻止保存；保存草稿不会改变现场运行的发布版本。

公共模板改动影响所有引用它的视角。需要例外时复制模板，再让特定视角引用副本；删除非默认模板时其引用恢复继承默认。

## 数据来源

- 固定文字／数值：标题、标签、说明等。
- 悬停对象字段：`hover.device.name/id/modelName/status/workshopName/lineName`；`hover.part.name/id/group/description/hint`。
- 部件参数：`hover.part.points.N.name/value/text/unit`。N 为当前部件关联点位索引；可新增元素，运行层不再限制只取前三项。
- 设备 PLC 点位：保存语义点位键，运行时仅在当前悬停设备内匹配，不把预览设备 ID 写死。缺失、重复、异常和过期的读数显示空值提示。
- 外部数据集：复用已配置的数据库／HTTP 数据集。查询参数可使用当前 `deviceId`、`partId`、`workshopId`、`lineId`、`viewId` 和大屏参数。每个元素可选择不同数据集及字段。

模板默认使用当前悬停对象；历史导入中明确指定的固定设备／全局来源仍保留。数据源账号和密码不写入模板或发布文档。

## 兼容与运行

旧设备提示的标题、说明、字段、点位及开关自动迁移；旧部件提示保留默认样式和关联点位。模板以 `document.tooltipTemplates` 嵌套保存，各视角只保存引用，不写入主画布组件表或 Unity 组件清单。

Unity 保留模型命中、高亮和点击下钻。Web 浮层负责模板渲染、跟随鼠标、边缘避让和离开隐藏；预览不会改动全局选中设备。鼠标移动不触发数据库请求，悬停对象切换会取消旧请求并忽略迟到响应。

## 验证入口

- 前端：`npm test`（frontend）。
- 后端：`npm run test:tooltip-templates`（backend）；亦包含在标准后端测试套件。
- 隔离 UI 冒烟：`node tools/tooltip-template-ui-test.cjs`，需可解析的 Playwright；可用 `PLAYWRIGHT_MODULE`、`BROWSER_EXECUTABLE` 指定本机依赖。它使用专属测试数据库与后端，不修改现场数据。
- 主画布多选回归：`node tools/designer-multiselect-ui-test.cjs`，同样使用隔离数据库与浏览器，验证 Ctrl / Command 点选、取消、多选拖动、锁定及撤销重做。

前端构建后刷新后台；常驻后端需重启以加载新保存／读取协议。已有现场模板不会自动发布，仍由用户保存并发布。
