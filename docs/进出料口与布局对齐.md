# 进出料口配置与布局对齐

## 配置入口

- **模型库 → 模型管理 → 进出料口**：先在模型资产列表选择设备模型，再进入上方独立的“进出料口”工作步骤；列表行内不再重复设置入口。
- **产线管理 → 画布选中一台设备 → 工具栏“进出料口微调”**：沿用已有实例微调，只保存该设备的偏移，不修改同型号其他实例；需设备编辑权限。

设备管理的已放置和未分配设备表不再重复展示“进出料口微调”按钮；编辑和删除操作保留，已有进出料口配置不因此删除或改变。未新增其它设置入口。

进料口和出料口均为**可选**，只用于进出料动画的交接对齐。没有小车、无需交接对齐的设备不用配置，可直接选择其他模型工作步骤；不会因此影响模型使用或发布。页面不再重复展示顶部说明横条、“跳过此项”及常驻“重新读取”按钮；读取失败或版本冲突时才显示对应恢复操作。

### 普通操作：选择口 → 点下沿 → 保存

1. 左侧选择“进料口”或“出料口”。不用勾选启用，也不用切换定位模式。
2. 在右侧模型上，点击口下沿与轨道／料盘齐平的**单个送料基准点**。不框选区域，不设置口的宽高。画布立即显示点标记和高度标签；重新点击即可改点。
3. 点击“保存配置”后生效。点击空白、拖动旋转和滚轮缩放不会设点，也不会自动保存。可用“完整视图”恢复观察范围，“清除选点”后保存可恢复未配置。

一个口已设置后，另一个口的设置区会出现「与进料口同位置」或「与出料口同位置」。点击复制当前已设置口的 XYZ 到目标口草稿；已有目标方向保留，新目标沿用源方向，关联节点随所复制点，两个口仍可独立重选。此操作不自动保存，也不移动产线设备。实例微调复制的是实际有效位置，再换算为目标口相对模型默认的偏移，并保留目标方向微调；模型未设置目标口时不能凭实例快捷操作创建默认口。

坐标、方向和辅助定位收在默认折叠的“高级微调”。XYZ 使用原始 glTF 模型坐标；Y 是送料基准高度，不是整台设备的总高度或炉门中心，标签不擅自假定模型单位。设备缩放和朝向由实例布局变换处理。

高级区可搜索选择节点、取节点中心或底部作为辅助。中心／底部只是几何辅助，须核对实际承料面。已有 CAD 辊道或多用炉口结构可读取建议，需点“应用建议”并保存才成为默认配置；未配置的出口不自动假定为入口。

实例微调也可直接点击模型选点，只保存相对模型默认点的本地偏移，保留已有方向微调；支持恢复沿用默认。模型没有该口时不能凭实例偏移制造新口，可直接跳过。模型和实例编辑均带 revision；读取失败、并发冲突会保留草稿，不覆盖他人的新配置。切换模型/页面会确认未保存修改，读取或保存中不能切换工厂。

## 前后对齐

**产线管理 → 进料面前后对齐**。

1. 选择已选设备、指定设备线或当前产线全部设备线。
2. 选择入口/出口；限定同一设备线时可指定基准设备，跨设备线时各线按其最靠近导轨的料口面独立对齐。
3. 生成预览：灰色线框是原位置，绿色是预览料口，橙色是基准；表格列出前后坐标和调整量。
4. 确认并应用后整批保存。取消或关闭不写入任何设备配置。

仅改变 `pos_z`，不改变 X 间距、Y 高度、朝向、缩放、PLC 参数、设备线绑定或模型结构。导轨上的小车不参加这一操作。方向必须垂直于导轨且朝向同侧；不符合时先调整布局朝向或明确的料口方向，不自动旋转设备。

## 送料高度对齐

**产线管理 → 送料高度对齐**。

明确选择范围和保持不动的基准设备，可使用小车“出料口”作为基准、炉子“进料口”作为参与口，将所选口下沿的基准点高度对齐。不会自动对齐整条产线。只有主动使用对齐操作时，参与口才需要已配置；没有对齐需求可以不使用此操作。只允许同一产线本地坐标内已放置的对象，不混用车间级或未放置设备。

预览确认后仅改变其他设备的 `pos_y`；保持基准设备自身位置、所有 X/Z、朝向和缩放。此操作抬高/降低整台展示模型，可能改变底座与地面的关系，应在三维预览中检查，不会变形 CAD、修改原 GLB 或调整现场机械。

## 模型下拉菜单的设置状态

右上角的模型选项直接附带本页状态，不用逐个切换模型核对：

- **进出料口**：未设置、仅进料口、仅出料口、双口已设置；非法保存配置显示「配置异常」。只看模型口配置，不把实例微调或几何建议算作已设置。
- **拆解布局**：未设置、默认布局、已设置 N 个部件。系统自动生成的零偏移部件不代表手工布局；专用布局保存会建立标记，因此主动保存原位也算已设置。旧版有非零偏移/旋转的布局继续识别。
- **部件动作**：未设置、已设置 N 项、内置 N 项。内置演示与已保存动作绑定分别显示，不表示现场 PLC 已连接；已退役的自定义工艺动画不计入。

以上只读取已保存的模型配置；未保存草稿不改变菜单状态，成功保存后菜单即时更新。

## 保存边界

- 产线布局有未保存修改时，先保存产线再预览。
- 参数、范围、基准、设备或模型配置变化后，旧预览失效，必须重新生成。
- 后端核对测量前的设备、模型及产线布局快照；任一来源变动，整批拒绝，无部分移动。
- 模型口配置、实例偏移和对齐保存分别使用窄接口，不借用整台设备 PUT 改写其他配置。
- 配置更新通过现有同步机制发布，预览不连接或写入 PLC，不覆盖安装版客户端。
