# 进出料口配置与布局对齐

## 配置入口

- **模型库 → 模型管理 → 进出料口**：先在模型资产列表选择设备模型，也可点该行的“进出料口”。
- **设备管理 → 对应设备 → 进出料口微调**：只保存该设备的偏移，不修改同型号其他实例。
- **产线管理 → 画布选中一台设备 → 进出料口微调**：同一实例编辑入口，需设备编辑权限。

模型配置区分别设置入口和出口。XYZ 使用原始 glTF 模型坐标；Y 是送料高度，不是整台设备的总高度。水平箭头指向来料一侧，设备缩放、朝向与镜像由实例布局变换处理。

可搜索选择节点、取节点中心或底部作为辅助，也可点击真实模型表面定位。中心/底部只是几何辅助，须检查实际承料面；不要把炉门中心误当送料高度。已有 CAD 辊道或多用炉口结构可读取建议，需点“应用建议”并保存才成为默认配置。未知模型不会凭空生成送料口，未配置的出口不自动假定为入口。

实例微调使用模型本地坐标偏移和水平角度，支持恢复沿用默认。模型和实例编辑均带 revision；读取失败、并发冲突会保留草稿，不覆盖他人的新配置。切换模型/页面会确认未保存修改，读取或保存中不能切换工厂。

## 前后对齐

**产线管理 → 进料面前后对齐**。

1. 选择已选设备、指定设备线或当前产线全部设备线。
2. 选择入口/出口；限定同一设备线时可指定基准设备，跨设备线时各线按其最靠近导轨的料口面独立对齐。
3. 生成预览：灰色线框是原位置，绿色是预览料口，橙色是基准；表格列出前后坐标和调整量。
4. 确认并应用后整批保存。取消或关闭不写入任何设备配置。

仅改变 `pos_z`，不改变 X 间距、Y 高度、朝向、缩放、PLC 参数、设备线绑定或模型结构。导轨上的小车不参加这一操作。方向必须垂直于导轨且朝向同侧；不符合时先调整布局朝向或明确的料口方向，不自动旋转设备。

## 送料高度对齐

**产线管理 → 送料高度对齐**。

明确选择范围和保持不动的基准设备，可使用小车“出料口”作为基准、炉子“进料口”作为参与口。只允许同一产线本地坐标内已放置的对象，不混用车间级或未放置设备。

预览确认后仅改变其他设备的 `pos_y`；保持基准设备自身位置、所有 X/Z、朝向和缩放。此操作抬高/降低整台展示模型，可能改变底座与地面的关系，应在三维预览中检查，不会变形 CAD、修改原 GLB 或调整现场机械。

## 保存边界

- 产线布局有未保存修改时，先保存产线再预览。
- 参数、范围、基准、设备或模型配置变化后，旧预览失效，必须重新生成。
- 后端核对测量前的设备、模型及产线布局快照；任一来源变动，整批拒绝，无部分移动。
- 模型口配置、实例偏移和对齐保存分别使用窄接口，不借用整台设备 PUT 改写其他配置。
- 配置更新通过现有同步机制发布，预览不连接或写入 PLC，不覆盖安装版客户端。
