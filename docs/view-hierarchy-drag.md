# 视角编排

- 原图标改为六点拖拽手柄。拖到行中间设为子级，拖到行上/下侧调整同级顺序；拖到列表底部的临时区域移为顶层。整棵子树一起移动，父级与返回视角同步更新，禁止自身/后代/返回环路。
- 去掉地图和厂区视角名称原来的 01–07 前缀，不改 ID 或自定义视角名称。
- 右键“隐藏此视角”只暂时隐藏编排层级项；子视角在层级图和关系选择框中接到最近可见上级。不会删除或停用实际画面，也不改原始连接；在“已隐藏”中恢复。至少保留一个可见项。
- 拖动、隐藏、恢复沿用草稿、撤销/重做和权限机制；保存草稿后重新打开保留。拖动不会自动发布，正式镜头关系仍在保存并发布后应用。

无需新依赖、后端或 Unity 更新。仅前端页面刷新后使用，不停止采集。

验证：`npm --prefix frontend test`（485 项）、`npm --prefix frontend run build`；`node tools/view-hierarchy-ui-test.cjs` 使用隔离 SQLite 与真实设计器，覆盖真实鼠标拖动、保存 API、撤销重做、隐藏/恢复/重开、环路拒绝、只读账号、1366/1600 窗口。依赖通过现有 `PLAYWRIGHT_MODULE` / `BROWSER_EXECUTABLE` 指定，不操作现场会话。
