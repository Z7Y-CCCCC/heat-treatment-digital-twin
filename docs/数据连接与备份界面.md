# 数据连接与备份

设置页按用途横向切换：**主库连接、外部数据源、自动备份、备份记录与保留、整站灾备**。一次只显示一类配置，不再纵向堆叠所有卡片。

- 切换标签保留各表单草稿，不会自动保存、发起备份或更改连接。
- 备份记录、数据源列表限制高度，内容较多时在列表内部滚动。
- 支持方向键、Home / End；窄窗口下标签横向滚动。
- 页面授权及连接、备份、恢复接口保持不变；不可用的备份服务显示明确提示。
- 局域网电视搜索失败的同一提示只显示一处。

验收：`tools/data-settings-ui-test.cjs` 使用独立本地夹具，覆盖标签隔离、草稿保留、32 条备份内滚动、键盘操作、独立保存、不可用状态和投屏提示去重。不会操作正在运行的大屏或正式数据。

前端构建后刷新后台页面即可加载，不需要重启后台或采集服务；刷新前应保存当前编辑。
