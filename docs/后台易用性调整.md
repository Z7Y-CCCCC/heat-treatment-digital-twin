# 后台易用性调整 · 2026-11-05

## 本轮变更

- “批量添加与排布”来自 [PR #18](https://github.com/Z7Y-CCCCC/heat-treatment-digital-twin/pull/18)，具体提交 `982498a067fa901614068a0abe28cd4e99a0922c`。核对 PR 提交列表及合并祖先关系后，只删除该弹窗、排布算法和入口；保留同 PR 的 CAD/工艺动画、送料高度等改动，也保留普通设备池拖入、多选拖动和等间距。
- 删除产线的三步说明条及车间编辑中的重复返回箭头。产线选择、创建和配置移到画布上方；配置默认收起，展开区局部滚动，画布不再让出左侧配置宽度。保留已有空间、设备线、导轨、设备位置与保存流程。
- 动作包导出改为搜索＋多选标签：显示真实编译动作与部位动作数量，悬停显示具体名称。每个选中模型分别导出一个有效 ZIP；不合并或丢失独立模型的标识。
- 可一次选择最多 32 个 ZIP，逐个检查后确认导入；每项单独显示结果，坏文件不阻断其他文件。串行处理限制内存峰值；重试跳过成功项。每项具有稳定请求标识，后台对同一次请求幂等，避免响应丢失后重试重复建模。
- 文件选择按钮统一为后台已有的描边圆角样式。加载画面保存按钮复用公共按钮样式。
- 顶栏 `Aa` 可调后台文字 100%—200%，默认 115%；仅本机保存，跨刷新保留，不上传账户/工程数据。后台字体改用一个共享缩放变量；不使用画布 zoom 或 transform，不改 Unity 模型坐标及发布组件字号，离开后台还原变量。
