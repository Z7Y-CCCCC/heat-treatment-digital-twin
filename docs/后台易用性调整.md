# 后台易用性调整 · 2026-11-05

## 本轮变更

- “批量添加与排布”来自 [PR #18](https://github.com/Z7Y-CCCCC/heat-treatment-digital-twin/pull/18)，具体提交 `982498a067fa901614068a0abe28cd4e99a0922c`。核对 PR 提交列表及合并祖先关系后，只删除该弹窗、排布算法和入口；保留同 PR 的 CAD/工艺动画、送料高度等改动，也保留普通设备池拖入、多选拖动和等间距。
- 删除产线的三步说明条及车间编辑中的重复返回箭头。画布上方仅保留产线选择、新增及数量按钮，不再有“产线与轨道设置”和展开卡片。新增产线改为弹窗，仍为 ID、名称、所属车间三个字段；创建失败保留草稿，禁止重复提交，关闭不依赖鼠标移出或遮罩点击。
- 产线下拉菜单可搜索，每行带垃圾桶；仍需输入产线名称确认永久删除及查看关联项。原有名称、车间、排序编辑通过同一行的编辑图标保留，应用后仍需保存产线结构。
- “设备线 / 导轨”数量改为凸起的可点击胶囊，分别在下方打开浮窗，保留添加、删除、名称、偏移、长度编辑。新增“选中”会自动滚动到相应画布形状、聚焦并高亮，不移动设备、不写数据库；只读账号也能选中，但不能修改。仍保留最后一条设备线删除保护、明确保存与放弃修改流程。
- 动作包导出改为搜索＋多选标签：显示真实编译动作与部位动作数量，悬停显示具体名称。每个选中模型分别导出一个有效 ZIP；不合并或丢失独立模型的标识。
- 可一次选择最多 32 个 ZIP，逐个检查后确认导入；每项单独显示结果，坏文件不阻断其他文件。串行处理限制内存峰值；重试跳过成功项。每项具有稳定请求标识，后台对同一次请求幂等，避免响应丢失后重试重复建模。
- 文件选择按钮统一为后台已有的描边圆角样式。加载画面保存按钮复用公共按钮样式。
- 顶栏 `Aa` 可调后台文字 100%—200%，默认 115%；仅本机保存，跨刷新保留，不上传账户/工程数据。后台字体改用一个共享缩放变量；不使用画布 zoom 或 transform，不改 Unity 模型坐标及发布组件字号，离开后台还原变量。
- 删除模型验收权限后的升级兼容：旧账户文件中的 `models.publish` 布尔字段在读取时退役，保留其他合法授权，不改密码或重新创建账户；新建/编辑权限仍拒绝未知字段。历史模型记录仅管理员可维护，普通编辑不能伪造发布历史。对应 HTTP 权限测试同步调整，没有恢复已删除的验收页面。

## 设计参考

- [Microsoft Fluent 2：Tag picker](https://fluent2.microsoft.design/components/web/react/core/tagpicker/usage)：使用标签表示多选值，保留搜索与键盘操作。

- [W3C：Resize Text](https://www.w3.org/WAI/WCAG21/Understanding/resize-text)：支持用户放大文字并保持内容和操作可用。本轮做页面回归，不将有限页面测试宣称为完整 WCAG 认证。
