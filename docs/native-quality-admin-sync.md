# 大屏与后台画质同步

- 后台选择框显示 Unity 当前确认的档位，不再将已保存的启动默认值误当成当前运行状态。自动模式保留“自动识别”的含义。
- 胶囊按钮、F1/F2/F3 与后台选择框双向同步。后台页通过同源 BroadcastChannel 转发给现有原生画质桥，不新增后端服务或常驻进程；两张原生 WebView 使用同一 WebView2 环境。
- 只接受递增版本的原生确认状态，不乐观宣称切换成功；仅转发画质白名单命令。新开后台会查询最新状态，跨页面不重播成功气泡，卸载时关闭订阅。
- 临时运行切换不自动写后台设置，也不会仅因收到状态就产生未保存草稿。管理员点击“保存当前参数”时保存当前档位，沿用原有权限和窄字段 API，不重启采集。
- 移除“模型几何策略”的只读说明框。它从未是可配置功能；本次未添加模型减面，也未改变 Unity 模型加载或网格优化逻辑。

更新后保存编辑，使用程序顶部刷新按钮刷新大屏数据层与后台页面；不需要重启 Unity、后端或采集器。

验证：前端 492 项测试、生产构建通过。`node tools/quality-admin-sync-ui-test.cjs` 在隔离后端和两个真实浏览器页面验证胶囊→后台、快捷键→后台、后台→原生桥、显式保存和重新打开；原生确认由受控 fixture 提供，不冒充本机 GPU/Unity 画质验收。本机真实原生链路可另运行既有 `tools/native-quality-ui-test.cjs`。
