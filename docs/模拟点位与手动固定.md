# 模拟点位与手动固定

- 模拟模式按当前工厂已保存的点位定义生成数据，包含新增的 READ / READ_WRITE 点位及数字、布尔、文本、日期时间类型；WRITE-only 点位不伪造读取数据。
- 点位监视表内显示“模拟 · 自动”或“模拟 · 已固定”，与 PLC 实采区别开。
- 有点位编辑权限的用户可双击“当前值”（或聚焦后按 Enter），输入表格中的工程值，选择“保存并固定”。该值不再重复应用比例/偏移/公式，也不会被下一次模拟刷新覆盖。
- “恢复自动”解除单个点位的固定值。编辑中的草稿不会被监视表自动刷新覆盖，Esc 取消。
- 固定值保留在当前模拟引擎的内存中：切换页面、刷新浏览器、新增点位及不改变该点位语义的配置热更新不会清除；退出模拟模式、停止/重启引擎或修改该点位数据类型/映射后清除。不写入 PLC，也不修改已保存的点位定义。
- 服务端以工厂、设备和点位 ID 校验归属，并再次检查当前引擎确实运行于 simulation 模式；仅前端显示模拟状态不能越权修改。

接口：`PUT /api/datapoints/:id/simulation`，JSON `{ "value": 123 }`；`DELETE` 同一路径恢复自动。两者均需要点位 edit 权限、有效会话及 CSRF 校验。读写点位没有实际 PLC 写入操作；真实/外部接口模式拒绝该接口。

验证：`npm --prefix backend run test:simulation-points`、前端 `simulation-point-value.test.mjs`、`node tools/simulation-point-edit-ui-test.cjs`。测试均使用隔离数据，覆盖采集子进程 IPC 与无采集插件的大屏本地模拟两条运行链。
