# 离线激活与厂商签发

## 已实现的流程

```text
新电脑安装并启动服务
  ├─ 有效授权 → 继续加载 Unity → 原登录/后台流程
  └─ 无授权/已过期 → 加载页等待激活
       复制指纹 → 厂商签发 → 粘贴激活码 → 本机验签/匹配/保存
         ├─ 失败：保留输入和原授权，显示简短错误
         └─ 成功：恢复初始采集并继续加载 → 原有首次设置后台密码
```

首次激活不需要管理员账号；它**不创建账号、不自动登录、不返回管理会话**。激活后的账号权限、中文账号、六字符密码策略均沿用已有实现。运行中的有效授权更新不重启采集。

## 界面

- 加载窗口：本机指纹、复制、激活码、激活并继续、退出；等待动画保持运行，未激活前不启动 Unity。
- “授权与版本”：授权摘要、版本、本机指纹、激活记录；管理员可打开折叠的“续期 / 更新授权”。
- 历史默认每页 10 条，点击单条才展开其激活码；不把长码塞进表格。
- 厂商工具：根目录 `厂商激活码工具.cmd`，轻量 Node + 系统浏览器，无 Electron。首次初始化密钥、绑定指纹签发、永久/限期授权、复制/TXT 导出。

## 生产约束

- Windows 服务始终强制校验授权；缺少公钥不会转入免授权模式。公钥来自安装程序资源，不从普通客户可编辑的页面提交。
- 正式资源准备必须提供 Ed25519 公钥。厂商私钥、已签发记录及生成器不进入客户安装包；测试也不能使用生产私钥。
- 激活接口只在回环地址工作，并校验 Host、Origin、跨站标记和进程级随机 nonce。只接受签名有效、尚在有效期、匹配本机 v2 指纹的码；已激活后禁用匿名重装入口，更新授权继续走管理员权限和 CSRF 校验。
- 历史接口不继承公开许可证状态接口的匿名访问豁免，须有“授权与版本”查看权限。签名文档不含密码或私钥。
- 新授权绑定 OS 机器身份散列；旧版安装锚点签名保持兼容。硬件/系统查询瞬时失败时尝试上次成功身份，避免一次查询故障误换指纹。完全离线方案不声称能抵抗本机管理员篡改、系统镜像克隆或系统时钟回拨。
- 采集启动被初次授权拦住；成功激活才触发幂等启动。更新有效授权不重启运行中的采集。已有现场程序不会在修改源码时被本次验证脚本重启或更改许可证。

## 参考（不是声称复制其内部算法）

- [MathWorks：手动和离线激活](https://www.mathworks.com/help/install/ug/activate-matlab-installation-manually.html)：获取离线电脑信息、生成许可证文件、使用激活客户端导入。
- [JetBrains：离线激活码](https://sales.jetbrains.com/hc/en-gb/articles/360016995379-Activating-JetBrains-IDEs-with-an-offline-activation-code)：粘贴或导入激活码，激活成功后继续使用。
- [Autodesk：激活码适用范围](https://www.autodesk.com/uk/support/download-install/individuals/keys/determine-whether-you-need-an-activation-code)：较新产品不再支持旧的人工离线认证，不能把旧版流程误称为所有大厂当前统一标准。

本项目选择的是适合工业隔离网的离线签发流程；Ed25519、历史文件结构、权限边界是本项目的实现选择。

## 验证

```powershell
node backend/scripts/license-test.cjs
node backend/scripts/offline-activation-test.cjs
node tools/activation-flow-ui-test.cjs
npm --prefix frontend test
npm --prefix frontend run build
```

UI 验收需可用的 Playwright，沿用项目的 `PLAYWRIGHT_MODULE`、`BROWSER_EXECUTABLE` 设置。它启动独立签发服务、独立 SQLite 后台和隐藏的 Electron 测试窗口，使用真正的启动预加载桥及激活门控，随后进入真正的后台首次密码设置页面，验证续期和历史。私钥、账号、截图、日志都在忽略的 `output` 内，不操作现有现场服务。

安装包 MySQL 和 Windows 服务冒烟使用单独的测试公钥视图及临时签发密钥，不读取生产私钥，也不改写原安装资源。此类自动化不等于已在全新物理电脑上完成 NSIS/SCM 安装验收；该验收需在交付前另做。该功能源码更新也不代表旧安装包已重新生成。
