## 用户只需配置什么

1. 采集点位：小车目标工位数值、到位 BOOL，以及各设备实际具备的进料／取料、出料／送料 BOOL。
2. **设备运动配置**：选目标、到位两个点位，导入／核对 PLC 工位编号与作业设备；默认勾选到位平滑对齐。不填速度、加速度、实际距离或米制比例。
3. **模型管理 → 进出料口**：先选模型，再在“配置对象”选具体设备，绑定该设备的进出料信号。已有料口位置直接复用。点位保存在设备实例，不进入共享模型或动作包。
4. 双侧作业的小车在同页选择 **旋转小车 · 简模**，保存。没有新增旋转角度点位。
5. 门、推链等机构动作仍在动作绑定里选对应信号；进出料信号配置不会代替这些独立动作的点位绑定。支持的动作包由 Unity 执行同一套定义，不需要手工重做 Unity 动画，也不是翻译任意 Three.js 脚本。

料口配置不要求小车和固定设备两侧信号严格同步；一侧实际具备的有效信号即可驱动对应示意。缺少信号、信号冲突、断线或错误类型时不编造真实完成状态。

## 已验收的显示行为

- 小车平移只用目标工位和到位反馈；移动过程中不要求中间位置百分比。
- 旋转简模底盘不转，上平台、动态料口和已取回的物料一起转；转到对接方向后才交接。普通单向车不会向背面穿车送料。
- 同一真实停车坐标可对应两侧的不同目标设备，不额外要求小车再移动一次。不同停车坐标不能继承上一站到位。
- 送料后物料留在目标设备；取料后物料回到上平台，继续随车移动。对方较晚信号合并去重，断线冻结。
- 将来有精细旋转车模型时，改选“旋转小车 · 模型转台”并指定唯一上转台节点；复用现有工位和信号。更换模型后仍需核对模型坐标和料口位置，不能承诺任意模型无须检查即可替换。
