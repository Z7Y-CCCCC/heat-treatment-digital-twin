# 工厂显示与采集开关

- **工厂与区域 → 大屏显示**：仅控制地图、街道、工厂及其下级实时大屏入口。允许隐藏任意工厂（包括正在查看的工厂），不切换后台编辑范围，不停止采集。
- **系统设置 → 数据通路 → 工厂采集**：独立控制该工厂的内置 PLC / 模拟采集。隐藏的工厂也可采集，显示的工厂也可停止采集。其他工厂的采集进程、连接及状态不重启。
- 隐藏工厂仍保留完整配置和后台选择入口；已经打开的实时工厂视角返回地图。后台配置与预览不受隐藏影响。

## 兼容与权限

旧列 `factories.is_enabled` 现在仅代表大屏显示；新增 `collection_enabled`，迁移默认 `1`，不根据旧显示状态推断采集状态。内部 `active_factory_id` 仍用于兼容客户端场景上下文，不是“默认工厂”或编辑权限限制，重启时不因为隐藏而改写。

`PUT /api/factories/:id` 只修改显示/资料；`PUT /api/factories/:id/collection` 仅接受布尔 `enabled`，使用 `settings.data:edit` 权限。工厂资料编辑权限不能代替采集控制权限。采集进程暂不可用时保存期望状态并返回 `runtimeApplied:false`，不虚报已应用；进程恢复时读取持久化开关。

显示通知使用 `visibilityOnly`，不触发原生场景重建。采集通知独立为 `factory_collection_changed`；通过私有 IPC 定向重载对应工厂，不关闭管理 API / Unity。

## 隔离验收

```powershell
node backend/scripts/factory-display-collection-test.cjs
node backend/scripts/page-permissions-test.cjs
node backend/scripts/factory-isolation-test.cjs
node backend/scripts/collector-process-integration-test.cjs
npm --prefix frontend test
npm --prefix frontend run build
node tools/factory-enable-ui-test.cjs
```

UI 脚本使用隔离 SQLite、子后台及无头浏览器；可通过 `PLAYWRIGHT_MODULE` / `BROWSER_EXECUTABLE` 指定已有依赖与浏览器。测试覆盖迁移、全部隐藏、隐藏后编辑、采集不中断、独立停止/恢复、跨工厂连续性、重启持久化、权限与胶囊操作；不替代现场 PLC 实机验收。
