# 用户页面权限

## 管理员操作

系统管理员登录后台 → **用户与权限** → 新增账户 / 管理账户 → **后台页面权限**。

- 每个账户独立授权，覆盖工厂、车间、产线、设备、设备运动、拆解布局、编排器、模型库、点位映射、点位监视，以及组件配置和系统设置的子页面。
- 勾选“查看”后才能授予该页面的其他操作；取消查看会同时取消其操作权限。
- “新增 / 修改 / 导入”不包含删除和发布。模型发布需同时具有模型修改和发布权限；大屏版本发布 / 激活有独立发布权限。
- 可以使用“业务页面全部只读”“业务页面全部操作”“清空后台授权”快速设置，再逐项微调。
- 用户管理与后台安全仅系统管理员可用，不能通过权限矩阵委派。授权与版本页可委派查看，但许可证安装、备份恢复和完整项目包导入导出仍仅限管理员。
- 原来的查看大屏、启动、投屏、备份四项现场功能仍单独设置。后台页面授权不自动授予查看 / 启动大屏权限。
- 修改名称和权限保留账户会话，各请求按最新权限校验；停用、删除或重设密码仍撤销原会话。过期账户在本机账户列表保留用户名入口，但必须重新验证密码，不能直接切换。
- 新建“现场客户”默认具有设备管理、点位监视只读权限，其他后台页面仍需单独授权。
- 勾选“投屏管理 / 备份操作”同步打开“运行与投屏 / 数据连接与备份”的查看权限；不会连带授权修改连接、删除或恢复备份。取消对应页面查看时会同步取消快捷功能。
- 账户启用开关位于用户表格；支持分页、每页 10 / 20 / 50 / 100 条，停用即时撤销该账户会话。

## 生效范围与边界

- 旧账户没有 `pagePermissions` 时后台页面全部未授权；不会自动升级旧 customer / viewer / editor 账户。
- 用户有任一后台页面查看权限，即可进入后台。导航、子页面、保存的标签和 focus 入口均按权限过滤；切换账户会重新挂载工作区。
- 切换账户只更新 Unity 身份，不重新构建已加载的大屏场景。Unity 连接状态可由只读账户查看，不代表获得草稿预览或编辑权限；检测失败显示“状态不可用”，不会一直显示“检测中”。
- 前端禁用相应操作控件；后端按真实 URL、方法和请求字段判权，不信任调用者传来的页面名。
- 显示运行所需的工厂、车间、产线、设备、模型、配置等只读资料有明确的共享依赖。授予“查看大屏”会允许读取这些展示资料，并不授予后台修改权限。它不是按工厂 / 按单台设备的数据隔离功能。
- 编排与产线设备布局只能通过窄接口修改位置和布局字段；设备运动只能修改 movement 和所选运动点位的采样周期，不能借此修改模型身份或 PLC 连接参数。
- 点位批量同步只有在确实删除原有点位时才额外要求删除权限；旧的全量替换 batch 接口同时要求修改和删除权限。
- 模型元数据中的发布状态、版本、发布时间和发布历史受到额外发布权限保护，不能用普通修改接口绕过。
- 授权父级资源的删除包括它的层级级联影响，仍需原有的具名删除确认。请谨慎授予车间 / 产线删除权限。
- 空闲锁定后后台页权限失效；原有展示会话是否继续由现场功能权限决定。HttpOnly 会话 Cookie、CSRF 和来源检查保留。
- 受信 `ADMIN_API_TOKEN` / `MCP_API_TOKEN` 仍为全权自动化凭据；普通用户的 MCP 调用不能借用它们越权。

## 本机登录选择

- 大屏各层级共用右上角贴边账户入口。闲置约 2.5 秒收起，鼠标移到右上角或键盘聚焦后滑出；菜单打开或正在输入时不收起。

- 锁定页可下拉选择最近成功登录 / 切换过的账号，也可直接输入其他账号；默认选择当前账号，无当前账号时选择上次成功使用的账号。
- 最多保留 8 个用户名，30 天有效；切换后解锁不会覆盖其他已登录账号。重启软件或本机后台端口变化仍保留选择。
- 用户名提示存于本机浏览器配置的 HttpOnly Cookie，不保存密码，也不作为授权依据。选择用户名后仍需输入该账号密码；失败的登录不更新记录。

## 开发验证

```powershell
npm --prefix backend run test:page-permissions
npm --prefix backend test
npm --prefix frontend test
npm --prefix frontend run build
```

后端验证使用 `output` 下独立账户文件、独立 SQLite 数据库和随机本机端口，不操作已安装软件的账户和设备数据。

此改动位于源代码；已安装版需重新构建、更新后端与前端资源后才能使用新权限界面。数据库无需另建用户表，页面授权保存在原账户安全配置中。
