# 模型管理、拆解布局与双向试播

## 页面归属

- **模型管理**仅保留模型资产、进出料口、拆解部件三个入口。原第四步部位绑定不再重复出现；旧浏览器保存的第四步状态安全退回模型资产。
- **拆解部件**保留节点、部件结构、位移／转角、部件参数关联及导入交换；可携带当前模型跳转拆解布局。
- **拆解布局**统一为部件摆放、外壳与时序、镜头与标签。播放、反向组装、透视、暂停、进度及速度位于同一真实三维视口，不再分散在模型管理中。
- 次要恢复、重读和导出放入“更多操作”；窄屏将设置与视口上下排列，保持视口高度，避免浮动播放条压在表单上。
- **动作动画 → 部件动作**的原辊筒动作下提供进料／出料试播，不生成重复动作或重复 PLC 绑定。按料口法线和辊筒上表面运动方向确定正反，切换方向保持已播放相位。没有对应料口时明确提示先配置，不猜方向，不影响风机等动作。

## 保存与兼容

布局、外壳时序、播放速度和全局镜头使用同一草稿及保存版本。模型布局端点只额外允许白名单 `presentation` 字段，设备布局端点仍只允许位置。未知字段、错误类型、越界数值和过期版本均拒绝；不以归一化截断掩盖输入错误。

并发修改只重放本地改过的位置及显示设置，保留对方独立修改；相同字段冲突须确认。部件结构、点位关联、资产身份、发布记录及其他元数据不由此写入覆盖。拖拽、显示设置均参与未保存保护、撤销／重做及保存后基线更新。

后续按图生成动作固定 0 关、1 开，规则在根 `AGENTS.md`、资产交付规范和生成器适配中共同约束。现有旧包不自动迁移；可使用独立输出目录验证导出，不能覆盖现场资产或固定出厂模板。

## 验证边界

新增回归覆盖端点约定、模型显示设置白名单／并发合并、真实布局预览生命周期及辊筒坐标变换。`tools/model-workspace-ui-test.cjs` 在自建 SQLite/HTTP 与真实 Chrome/WebGL 中验证三入口、统一保存重开、播放／反向／暂停、窄屏无重叠，以及小车和固定设备双向试播；不连接现场数据库。

实际门规范导出只写隔离目录；本机现场配置、录像、截图、生成的 GLB／轨迹及构建输出不提交 Git。本次不构建安装包，不修改出厂画面模板。
