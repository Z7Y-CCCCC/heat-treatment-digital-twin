# 料口区域与实体对接校准

入口：**模型管理 → 进出料口**。料口测量与实体对接共用一页的右侧预览区：左侧点击 **框选料口区域** 才开始测量，点击 **检查小车对接与实体位置** 则切换为双实体预览，不再另开下方画布。这是可选配置，不会阻止普通模型、设备的使用。

## 1. 在真实料口面画区域

选择“模型料口位置”，分别配置进料口、出料口。**框选并保存的区域就是实际料口。** 默认处于浏览模式，框选按钮不选中：左键空白处旋转、右键平移、滚轮缩放，只改变观察相机，不创建或修改料口；已移除“浏览模型”按钮。

点击“框选料口区域”后，在同一个近竖直真实表面拖出矩形，或依次点击两个对角。完成选区、再次点击框选按钮或按 Esc 都返回浏览；切换料口也回到浏览。取消只清除未完成的角点，已完成的草稿保留，不自动保存。顶面、地面、明显倾斜面、近侧视、不同平面以及过小区域都会拒绝。

- 区域四角使用 **glTF 根节点局部坐标**（含模型内部层级变换，未乘设备摆放比例／旋转），按下左、下右、上右、上左保存。
- **送料基准点 = 模型 Y 较低的下沿中点**，不是区域中心、门板中心或屏幕上的“下方”。它应位于真实轨道／料盘交接高度。
- 区域法线来自所选实际面；交接方向是该**向外法线的水平投影**。进料口法线也指向来料侧，不指向炉内。已画型号区域不能通过高级坐标、方向输入挪离真实面；点错请重画。
- 边框和下沿圆点是配置辅助标记，不改 GLB、门板、滑架、动作包、比例或 PLC。完成后点击“保存配置”，成功／失败有提示；失败保留草稿。

## 2. 框选区域是唯一几何依据

型号保存的区域直接用于使用该型号的设备，不再被旧 `offset/yawDegrees` 移走或反向。选择具体设备后显式重新框选的区域，仅用于该设备；其根节点局部四角、下沿中点和实际面法线直接确定实际料口，不再二次叠加偏移或角度。协议中的旧标量字段保留用于兼容，不会修改其他设备、点位信号、机构或实体摆放。没有型号基准口时仍不能凭空保存设备口，应先给型号设置该口。

读取顺序统一为：本设备显式区域 → 型号区域 → 仅双方均无区域时兼容旧单点加相对偏移／角度。型号以后改变不挪动设备显式框选的区域；没有设备区域时则直接使用新型号区域。前端预览、后端有效口、自动排布与 Unity 使用同一规则。协议保持 `version: 1`，`region` 为可选字段；**读取不改写、重画或清空旧配置，也不迁移模型／动作包。** 已有区域不能被迟到的单点或结构建议覆盖，修改实际区域须重新框选。

## 3. 在同一右侧画布检查实体对接

先保存区域，再点击左侧“检查小车对接与实体位置”。原右侧模型画布切换显示小车与设备的两个实际模型，按适配的工位及小车自动读取几何预览；未配置时显示原因，不伪造对齐。可切换工位、小车和双方料口；左键旋转、右键平移、滚轮缩放仍只改变观察相机，正面／俯视按钮可恢复标准观察。

对齐偏差与实体调整、保存控件位于这块右侧预览区中。以毫米步长调整目标设备的真实左右位置与高度，预览不写入；只有明确确认“保存设备位置”才提交目标设备位置，并核对后端回读。小车位置、料口标记、型号、信号与 PLC 绑定不改变。再次点击对接按钮可返回模型；点击“框选料口区域”则返回模型并显式进入框选。

**点选测量错了应重画料口；实体不齐应调整设备实体，不能挪标记伪装对齐。** 两口标记重合不等于机械交接成功。仍须验证关门实际阻挡、开门确实让出料口，门板／滑架同步到位后，料盘与小车才可交接。新动作包继续遵循 **0 = 关门、1 = 开门**；旧包迁移另行审核，本功能不自动反转动作或现场 PLC 含义。

料口草稿和实体位置草稿分别保存。进入实体预览前，未保存的料口草稿会先询问是否保存；未完成区域不能提交。离开、切换对象、返回料口模型时都受未保存／忙碌守卫保护，取消确认保留当前模式和草稿。隐藏预览暂停渲染，保留相机及标记，不因切换重置现有配置。来源被其他编辑者更改会锁定陈旧预览，必须重新读取，不能覆盖并发修改。
