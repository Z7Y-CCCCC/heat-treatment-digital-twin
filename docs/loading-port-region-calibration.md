# 料口区域与实体对接校准

入口：**模型管理 → 进出料口**。原“料口选点／对接校准”两个页签合为一页：先在模型上画区域，必要时展开下方 **检查小车对接与实体位置**。这是可选配置，不会阻止普通模型、设备的使用。

## 1. 在真实料口面画区域

选择“模型默认料口位置”，分别配置进料口、出料口。在同一个近竖直真实表面拖出矩形，或依次点击两个对角；右键平移、滚轮缩放，“浏览模型”允许旋转观察。Esc、取消绘制或切换视图会取消尚未完成的角点，不自动保存。顶面、地面、明显倾斜面、近侧视、不同平面以及过小区域都会拒绝。

- 区域四角使用 **glTF 根节点局部坐标**（含模型内部层级变换，未乘设备摆放比例／旋转），按下左、下右、上右、上左保存。
- **送料基准点 = 模型 Y 较低的下沿中点**，不是区域中心、门板中心或屏幕上的“下方”。它应位于真实轨道／料盘交接高度。
- 区域法线来自所选实际面；交接方向是该**向外法线的水平投影**。进料口法线也指向来料侧，不指向炉内。已画型号区域不能通过高级坐标、方向输入挪离真实面；点错请重画。
- 边框和下沿圆点是配置辅助标记，不改 GLB、门板、滑架、动作包、比例或 PLC。完成后点击“保存配置”，成功／失败有提示；失败保留草稿。

## 2. 型号默认与设备微调

型号保存默认区域，使用该型号的设备可直接沿用。选择具体设备后重新画区域，仅保存该设备的 **offset／yawDegrees + region**：offset 和水平角度仍相对当前型号默认料口，不写回型号，也不修改同型号其他设备。没有型号默认基准口时不能凭空保存设备区域，应先给型号设置该口。

型号默认基准以后经用户编辑改变，设备有效区域按既有相对偏移／方向对齐到新的有效料口，保留区域宽高；这是读取时的显示计算，不改写设备已有配置。协议保持 `version: 1`，`region` 为可选字段。**旧单点及旧 offset／yaw 文档原样兼容；启动、更新、导入读取不会自动迁移、重画或清空。**

## 3. 展开实体对接检查

先保存区域，再展开“检查小车对接与实体位置”，选择工位与对应小车，显示两个实际模型；正面／俯视查看左右和高度偏差，以毫米步长调整目标设备的真实左右位置与高度。预览不写入；只有明确确认“保存设备位置”才提交目标设备位置，并核对后端回读。小车位置、料口标记、型号、信号与 PLC 绑定不改变。

**点选测量错了应重画料口；实体不齐应调整设备实体，不能挪标记伪装对齐。** 两口标记重合不等于机械交接成功。仍须验证关门实际阻挡、开门确实让出料口，门板／滑架同步到位后，料盘与小车才可交接。新动作包继续遵循 **0 = 关门、1 = 开门**；旧包迁移另行审核，本功能不自动反转动作或现场 PLC 含义。

料口草稿和实体位置草稿分别保存；离开、切换对象、收起实体检查时都受未保存／忙碌守卫保护。来源被其他编辑者更改会锁定陈旧预览，必须重新读取，不能覆盖并发修改。
