# 项目与资产迁移

画面级复用使用设计器的“导出模板 / 导入模板”（JSON）；复制工厂配置和本地资产使用“项目与资产迁移”（ZIP）。整站备份用于恢复完整环境，不是上述两种复用格式。

## 导出与创建副本

1. 保存源工厂中需要迁移的编辑。打开后台工厂管理，在“项目与资产迁移”选择“导出来源工厂”，点击“导出所选工厂项目包”。包只包含已保存数据。
2. 在目标程序同一页面选择 ZIP，点击“校验并预览项目包”。检查来源工厂、车间/设备/点位/场景/发布版本数量、资产数量和警告。校验会检查文件大小、清单、引用完整性及 SHA-256；更换文件后必须重新校验。
3. 填写新工厂名称。默认只创建新工厂；如需复制集团地图和启动加载画面，可勾选“同时应用包中的集团地图外观和加载画面（影响所有工厂）”。勾选会替换当前程序所有工厂共用的外观，不只是新副本。
4. 点击“创建新工厂并导入”。成功后从工厂列表进入副本检查。原工厂保留，当前编辑工厂不会自动切换。

包包含受支持的设备拓扑、点位、场景配置、草稿/发布记录、模型及本地引用资产，并自动替换副本的内部 ID 和资产路径。支持 glTF 本地依赖；远程 URL 仍需原远程服务。当前资产上限为 512 MiB，配置数据另有限额，超限会拒绝。

## 在新工厂接入真实数据

1. 导入副本默认使用模拟模式，设备采集关闭。PLC 地址、连接选项及数据库/API 账号不随包迁移。在新工厂的系统设置配置目标数据源，并核对设备与只读点位。
2. 打开新工厂的画面设计器，点击“重绑定数据”。为来源设备、点位、数据源、车间和产线选择当前工厂的目标。点位选项显示设备名、中文标签、技术键及 ID；设备与点位不匹配会被拒绝。
3. 数据库/API 组件进入“映射目标字段并验证数据”。选择目标表、数值/时间/排序/筛选字段，或接口 GET 路径和响应字段路径。可用“重新读取字段”刷新真实元数据；候选建议不能代替业务确认。
4. 对每项点击“预览实际数据”，核对含义、单位、时间和筛选口径，再勾选“我已核对字段含义及预览结果（空值也需核对）”。全部确认后点击“确认映射并载入草稿”。修改任一映射会清除对应旧预览和确认，需重新预览。
5. 检查地图/厂区、模型、设备下钻、图表及交互。保存草稿并发布，核对运行版本与实际数据后，再按现场流程启用真实采集。发布成功只代表版本已保存，不能据此推定未连接的 Unity 已收到更新。

导入设计模板或应用重绑定可以通过设计器撤销恢复原稿；取消映射不会应用未完成的方案。项目 ZIP 创建的是独立副本，应保留源工厂直到副本验收完成。

## 备份与验收

项目迁移完成后生成整站备份。备份恢复已覆盖迁移资产、共享外观资产、工厂数据源连接及备份选择。不要把不含连接凭据的复用 ZIP 当成整站灾备。

本轮已验证隔离项目迁移、字段映射回归、真实界面创建副本与发布，以及实际 10 分钟隔离耐久。物理现场的真实 PLC、客户数据库、Unity/WebView2/电视和 72 小时连续运行仍需验收；参见 [耐久验收说明](endurance-acceptance.md)。
