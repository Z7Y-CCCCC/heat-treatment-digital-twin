# 点位选择与部件描边修复

日期：2026-11-05。仅本机开发版与源码更新，不打包、不安装、不发布 Release。

## 修复范围

- 点位表格设备选择改为可搜索浮层。完整车间／产线／设备名称自动换行；浮层独立于表格滚动区，按视口定位，支持键盘、Escape、200% 字号，查看权限不能改选所属设备。
- 新点位整行绿色边框，以后端实际 ID 为准；保存失败保留，成功重读取得 ID 后消失，原有点位不误标。行 key 不再依赖正在输入的名称／地址，避免输入时重建控件，且不把临时 UI key 写入点位数据。
- 移除“组件配置 → 场景与光效”中的动作包导入／导出及无用回调。“模型库 → 动作动画”的两个按钮保留。
- 实时大屏部件悬停改为单层约 2 像素外边缘。所有命中部件网格先合并为遮罩，再只绘制遮罩外侧边缘，不改变原材质，不替换 PLC 材质，不画包围盒、不铺色、不加宽辉光。仍按场景深度排除不透明遮挡；原有自动透明遮挡物逻辑不删除。

## 修改溯源

- 可追溯引入部件双层绘制的是 `00ff810d282603f78ec073fb01a5a09bede5cf00`（`backup: snapshot project before performance optimization`，2026-09-27）：新增 6px、透明度 0.22 的宽辉光和 2.5px、透明度 0.95 的边线。
- `fd48ea956a2f74d7c91a1d1a2de54e869905658b`（2026-11-02）将相关代码整理为设备／部件共用入口，但沿用了上述双层参数；不是这次投屏设备记忆更新改出的。
- 旧 shader 用沿法线扩张的翻面壳，依赖模型本身写深度来遮掉内部。CAD 壳体、透明部件不写深度时，翻面壳可能露出为整片高亮；仅降低亮度或删除 6px 一层不能彻底修好，所以改为外侧遮罩描边。
- 场景光效中动作包按钮来自 `a0c2fc3` 的资产导入改动；本轮只删除错误页面入口，不删除动作包能力。
