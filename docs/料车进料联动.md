# 设备联动与清洗机工艺动画

入口：后台管理 → 模型库 → 动作动画 → 设备联动。

默认使用 `ultrasonic_cleaner_cad` 清洗机和 `photo_transfer_cart_v6` 料车测试；也可切换多用炉 V6、回火炉 V6。

流程为料车定位 → 门打开 → 推链送料 → 推链退回 → 门关闭。演示中物料与推链分别计算位置，退链时物料留在设备内；推料前门已开到位，关门前推链已归零且物料已越过关门平面。清洗机沿用经过几何校验的关闭端 `-0.686`、打开端 `0.22`。

支持开始、暂停、复位、变速、进度拖动、步骤预览、各步骤时长设置、内部透视和送料近景。时长仅作用于本次演示，不写入生产配置。

## 清洗全过程

清洗机进入“设备联动”后默认选中“进料＋清洗联动”：上述 5 个进料工步之后，连续演示注液、加热、喷淋清洗、超声清洗、排液 / 回液、吹扫、开门待出料，共 12 步，默认总时长 60 秒。界面提供“从头播放完整联动”，可从任何预览位置或“仅进料”模式直接重新播放全流程；送料关门不作为完整联动的结束条件。多用炉和回火炉仍使用原进料流程。

设备联动预览上方始终显示进料 → 注液 → 加热 → 喷淋 → 超声 → 排液 → 吹扫 → 开门待出料的完整流程，并高亮当前阶段。“自动跟随工步”默认开启：送料后自动切换工艺近景，让液位、喷淋、波纹及气流清楚可见；开门待出料时切回送料区域。可取消自动跟随并手动调整视角。部件页的单步预览不会传入或中断设备联动的完整播放。

“部件动作”页选中 `ultrasonic_cleaner_cad` 后，六种工艺效果直接列入下方动作节点（默认 6 个工艺节点 + 20 个门体绑定，共 26 项），支持统一搜索和分页。顶部“工艺动作 6”按钮会选中对应节点并定位其页码；点击节点或预览按钮直接在本页右侧播放，保持“部件动作”页，不跳转到设备联动。右侧提供内部透视、暂停、重播、独立工步进度和停止预览，隐藏送料小车及轨道。选回门体节点或停止工艺预览后恢复原部件视图。

工艺节点是内置模拟效果，与保存的 PLC 部件绑定分开存储，预览不会向绑定元数据写入虚构点位。门体绑定的编辑/删除仍使用原始索引。需要观看完整工艺时，可主动切换到“设备联动 → 进料＋清洗联动”。

工步列表每页最多 6 项，播放及拖动进度时自动定位当前页。液面、流向粒子、波纹和气流统一使用流程时间，暂停、复位或跨工步跳转不会留下独立运行的效果。支持“工艺近景”与“内部透视”；透视同时显示包围清洗腔的震板内部。

喷淋发射位置参考真实 CAD 的 10 个喷淋支管；震板、风机外壳与加热器保持原位，通过运行高亮表达工作状态。超声微气泡与波纹是空化示意，未用大幅位移或整个风机总成旋转替代实际运动。注液按“清洗腔注液”示意；回液路线、模拟液位百分比、25–55 ℃模拟温度及干燥进度均不是现场测量或已确认管路。实际注液位置、回路和配方时序需按现场工艺校准。

`cleanerProcess.js` 提供可拖动的工艺状态，以及只读 `cleanerEffectsFromSignals()` 映射边界；`TransferFeedScene.applyProcessSignals()` 可接收后续明确映射的反馈值。字段为 `quality: 'good'`、`online`、`time`、`level`（0–1）、`temperature`、`fill/heat/spray/ultrasonic/drain/blow`、`wetness`（0–1）。坏质量、离线或缺失质量时保留液位和温度，停止活动流动效果。当前页面只使用演示状态，不订阅或写入 PLC。

当前是三维工序演示。现场跟随还需要确定具体料车和设备实例，并映射料车定位、门开/关到位、推链行程/退回到位、有料等 PLC 信号。当前入口不发送 PLC 控制指令。实际设备仍由既有 PLC 联锁控制。

新增实现：`frontend/src/three/feedSequence.js`（阶段与姿态）、`TransferFeedScene.js`（模型对齐与部件）、`ModelTransferSequence.vue`（演示页面）。测试包括实际模型的门口尺寸、物料包络、料车对齐和归零间隙，以及动作前置顺序与退链时物料留机。
