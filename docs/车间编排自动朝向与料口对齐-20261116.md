# 二维自动纠正朝向与靠轨距离

入口仍为车间编排中的“预览自动排布”，不新增校准步骤，不在拖动或保存时强制重排。

- 读取用户已校准的有效料口及实例覆盖，按真实模型的缩放、镜像和旋转计算方向。
- 在推荐方案中转动整台模型，使固定设备朝向导轨、小车朝向设备；转向后重新测量真实 CAD 外形。
- 不再要求不同模型的原点处于同一深度，改为按各自料口位置对齐靠轨距离。
- 左右 X、原高度、设备顺序、线长、PLC 工位、移动路径和料口配置不变，不修改模型比例或机构行程。
- 方案显示转向设备清单与料口箭头。取消不改草稿，应用后可整体撤销，顶部保存才提交原有原子事务。
- 姿态变化导致的碰撞仍严格检查；不能自动解决的具体设备提供“到三维调整”入口。

缺少明确料口、推拉轴与料口不平行、未知机构行程、多辆小车职责不明确，以及单向小车同时服务两侧时，不能猜测或生成虚拟反向料口。真实转台/双侧交接能力须在三维确认。原高度不自动拉齐，送料高度仍通过对接预览核对。

新方案以 `placementTemplate.mouthAligned=true` 记录其间距依据；旧布局读取时不迁移、不覆盖。新方案取消旧式纯展示的 2 米最小间距，使用真实外形、安全留缝与原行程共同计算，仍不允许相撞或扩大行程。
