# 拆解保存冲突与导航修正

## 导航

```text
模型库
├─ 模型管理
└─ 拆解布局
```

从“工厂建模”移除拆解入口。沿用原页面权限、选中设备和未保存切换确认；只有拆解权限的用户也能看到模型库分组。

## 保存根因与修复

之前的 SQLite 验收未覆盖 MySQL 原生 JSON：数据库字段被读成对象，而比较参数及保存响应使用 JSON 文本。空格、键序、数值表现和驱动表示差异会误报 409，甚至刚保存的版本也与重新读取不一致。

- 版本号按规范化 JSON 值计算；MySQL 使用原生 JSON 值比较，仍区分字符串大小写和数组顺序。
- 兼容当前仍打开的旧前端版本号，仅接受与数据库当前快照对应的版本，不取消并发保护。
- 真正冲突时只重放本地改动的部件，保留其他部件、PLC 绑定和时序；同一部件被双方修改必须确认。模型文件、节点或坐标系变化时不自动套用旧位置。
- 增加“导出草稿”和带确认的“重新读取布局”，避免失败后只能反复点击保存。
