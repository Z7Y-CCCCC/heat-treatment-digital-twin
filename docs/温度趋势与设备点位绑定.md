# 温度趋势与设备点位绑定

## 本次实际核查

2026-11-04 只读检查本机井式炉工厂：17 台设备均未配置采集点位；工厂数据模式为 `simulation`。原温度图从 `device.analog.actual_temp` 取得的是内置模拟器读数，不是已经调试完成的现场 PLC 数据。原 ERP / 部件样例导入也不等于真实业务系统接入。

本次没有填写猜测的 PLC 地址，没有切换采集模式，没有覆盖工程数据库，没有重启使用中的程序或采集服务。

## 如何配置

1. **点位映射**：先配置设备实际的温度 READ 点位、地址、单位及采样周期。地址必须依据现场点表。
2. **大屏设计器 → 选中温度趋势 → 数据来源 → 设备点位**：选择设备与点位；面板显示实际数据引擎来源、地址、当前读数、质量、采样时间。
3. 展开 **设备范围与刷新**：选择固定设备、跟随视角或多设备轮播，分别设置刷新与轮播周期。设备详细视角仍锁定当前设备；其他设备通过唯一的同类点位键匹配，缺失或重复时不冒用别台数据。
4. **内容**：设置曲线形式、颜色、线宽、数据点、图例；数值轴可自动适配或指定最小/最大值、轴标题、刻度精度、网格；时间轴可设置实时窗口和时间格式。
5. **保存草稿 → 保存并发布**：设计器与实际 WebView 使用同一个组件渲染器和配置。缺点位时可以保存空绑定，但不会生成示例曲线；不存在的已选点位、WRITE 点位、固定设备不匹配仍被拒绝。

## 数据边界

- 删除设计器硬编码的温度、产量、工单、报警和设备状态演示值。预览改为读取后台实际帧和点位响应；来源为模拟器时，管理端明确显示“内置模拟器”。大屏不额外堆叠提示文字。
- 原设备字段趋势在读取时可逆地转换为严格的点位绑定，不改原发布快照。没有配置点位则留空；后续明确保存才落盘。
- 曲线按**源采样时间**记录，不把缓存重复刷新当成新采样；使用完整 24 小时时间，保留真实零值。设备轮播分别保留窗口；坏质量、过期或读取失败显示缺口，当前读数不回退成历史最后一个“正常值”。
- 实时窗口是页面打开后累积的内存数据，最多 600 个样本，不伪装成已接通历史数据库。实时窗口默认 10 分钟，改变窗口会同步设置样本上限；页面关闭后该临时曲线不会保留。外部历史数据可使用已有数据集绑定。
- 一秒组件刷新不能提高 PLC 的实际采样频率；点位采样周期仍在采集配置维护。本次没有改变采集器调度和设备隔离。

## 验证范围

- 前端：坐标范围、单位、时间标签、缺失/零值、缓存去重、故障缺口、设备历史隔离、真实预览读取及失败清空。
- 后端：源模式、真实快照读数、过期判断、跨设备隔离、严格空绑定、非法点位拒绝；原设计器保存/发布/恢复回归。
- 隔离浏览器：配置实际 READ 点位的独立测试工程，经后端控制输入验证源→设计器→保存发布→同一 WebView 图表；验证无点位、自动/固定数值轴、230px 卡片可用绘图区、坏质量及恢复。
- 测试输入只属于隔离验收进程，不是现场数据。没有运行安装包、连接现场 PLC 或做长时间运行测试。
