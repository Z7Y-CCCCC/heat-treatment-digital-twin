# 产线批量添加与排布

产线管理顶部点击“批量添加与排布”，选择设备线或小车导轨。默认列出待放置设备，也可以切换到“本设备线全部”重新排布已放置设备。勾选设备后用 ↑↓ 调整顺序。

推荐“外形净间距”：例如设置 1 米，是前一台完整模型外沿到后一台模型外沿留出 1 米，而不是设备中心相隔 1 米。模型的原始偏心、朝向、设备缩放、型号默认缩放、实例倍率和镜像均参与计算。尺寸包含模型上伸出的管路等部件。

支持末尾追加、整组居中，以及指定首台设备外沿的产线局部 X 坐标。排列方向为产线 X 从小到大，不随工艺箭头反转；工步编号保留，新增设备分配不重复编号。设备线长度必须容纳完整模型，超出或与未选设备重叠时会提示，不自动挤小间距或改动线长。

点击“生成排布预览”查看位置、外形占宽和相邻净间距，预览不保存。再点击“保存 N 台设备排布”一次保存整组位置及设备线绑定，现场编辑器使用同一套产线局部坐标。只更新位置与布局绑定，保留 PLC、设备型号、朝向、比例和拆解配置。保存失败不会移动部分设备，关闭或取消预览不改变布局。
