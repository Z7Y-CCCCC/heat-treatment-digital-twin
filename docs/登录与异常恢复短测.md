# 登录、异常恢复与 Windows 安装短测

日期：2026-11-03。对象：2.3.2 开发候选。测试环境：Windows 11 Pro x64 / build 26200，Unity 2022.3.34f1c1，Node 22.13.1。

**结论不是“所有情况不会出问题”，而是下列已复现路径有自动化证据。未做长时间运行、真实 PLC / 采集测试，也未覆盖用户正在使用的工程。**

## 1. 方法与隔离

采用分层回归：契约/边界测试 → 浏览器实际交互 → 原生进程故障注入 → 随包应用首次启动 → 安装器编译与原生页面检查。参考 Microsoft 的运行环境分发和 Windows 应用验证方法，不把单元测试代替干净系统安装，也不宣称取得 Windows 认证。

- 所有测试账号、授权、数据库、浏览器配置和日志在独立 `output/` 或临时目录中。
- 故障注入只操作测试进程 PID / 父子关系，不按 `node.exe` 或 MySQL 名称全局结束进程。
- 随包启动验证使用测试目录内的授权签发材料；正式包公钥/厂商私钥和现场账号不修改。
- 未安装候选 EXE、未执行 Microsoft 运行库安装、未重启现场服务、未启用 Windows 虚拟化功能。

## 3. 修复内容

1. 后台连续恢复失败或无法安全回收旧进程时，取消原来的“直接退出整个大屏”；保留 Unity，并提供可操作错误。
2. WebView2 渲染进程异常自动重载；浏览器崩溃/渲染无响应时重建窗口宿主；宿主重建有频率上限，避免无限重启。
3. 增加桌面对原生窗口宿主的缺失检测与恢复；不把恢复页面实现成重启 Unity 场景。
4. 安装器及首次启动检查 Windows 版本/架构、WebView2 和 VC++；随包提供 Microsoft 签名的离线安装程序、SHA-256 和来源清单。
5. MySQL 中文路径链接目录与独立服务目录分离；安装器准备普通用户可创建私有子目录的权限，首次启动不重写机器级 ACL。
6. 修复 NSIS 编译中的字体指令、宏内源路径和卸载器无引用函数问题，仍保留编译警告视为失败。
7. 修复独立 ZIP 打包脚本使用却没有声明 `7zip-bin` 的依赖问题；仅验证归档，不执行采集。

## 4. EXE 安装界面

实际使用 NSIS/MUI2 原生安装向导，不是网页效果图。增加专用深蓝紫工业侧栏、品牌页眉、中文欢迎页、安装位置页、准备摘要、进度与完成页。数据采集明确作为独立可选插件。

`desktop/scripts/installer-preview.cjs` 从同一安装包含文件编译安全预览 EXE；`tools/installer-preview-ui.ps1` 对该进程的原生窗口执行页面检查和截图。它不安装程序、不写安装注册表、不安装运行库。截图在 `output/installer-preview/`。

安装候选已实际通过 NSIS 编译；**页面预览/程序解包启动不等于已经在干净系统完成安装、卸载、升级验收。** 依赖文件具有 Microsoft 签名，但本次主安装 EXE 为 `NotSigned`，还没有配置厂商代码签名证书，干净系统可能出现 SmartScreen/未知发布者提示，不能承诺没有该提示。

本机只读查询也确认：当前没有本产品 NSIS 卸载记录，没有 `HeatTreatmentCollector` 服务；根目录启动的是开发版，连接既有 MySQL 5.7.44（3307 端口）。因此“开发版能运行”不能冒充“该安装包已经在本机安装通过”。实际现场库和安装改动见另一份清单的第 0 节。

本机候选随包 MySQL 实际版本是 **9.2.0**，构建脚本默认来源为本机该目录；不同构建节点可通过 `DESKTOP_MYSQL_RUNTIME_SOURCE` 选择其他版本。不能把本次启动结果说成 8.4.13 的结果，也不能把旧版本数据库直接替换成另一个主版本的运行库当作“已验证升级”。正式发布前应固定数据库运行库版本并单独验收历史版本升级路径。

## 5. 仍待干净系统执行的发布门槛

| 环境 / 场景 | 当前状态 |
|---|---|
| Win10 22H2 x64 干净快照：离线安装、缺 WebView2/VC++、中文路径、普通用户首次启动 | 未执行；本机没有可用 VM |
| Win11 x64 干净快照：同上，以及 100%/150%/200% 缩放 | 未执行；不是用本机已有依赖代替 |
| UAC 拒绝、企业安装策略、缺可信根证书、断网验证 Microsoft 签名 | 分支有边界测试，真实策略机器未执行 |
| 升级旧安装包、卸载后重装、普通用户数据保留与注册表差分 | 源码/静态检查，未在干净系统实际安装执行 |
| 不同显卡 / 驱动、第三方杀毒拦截、真实断电或磁盘硬件损坏 | 未执行；不承诺自动修复 |
| Windows App Certification Kit / Windows 认证 | 未执行 / 未取得 |
| 长时间运行、性能耐久、PLC 或数据采集 | 按要求不在本轮范围 |

建议以干净快照分别完成：安装前后文件/注册表快照 → 离线安装 → 标准用户激活与建号 → 切换/锁定/退出与重开 → 故障恢复 → 备份恢复 → 卸载保留数据 → 重装。不能仅因为 CI 是绿色就公开宣称“所有 Win10、11 可用”。

所有数据、注册表、运行库、备份和卸载残留位置另见 [Windows安装与系统改动清单](Windows安装与系统改动清单.md)。
