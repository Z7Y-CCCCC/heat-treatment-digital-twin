# 数据驱动动作与双设备联动

## 本轮落实范围

实时联动采用“选择现场设备 → 选择数据中心已整理字段 → 选择模型动作 → 设置条件 → 保存并同步”的流程。工厂、车间、产线、设备逐级选择；跨工厂操作复用原有保存／放弃／取消确认，草稿按工厂和设备隔离。

数据来源不是可编辑的常量：只读采集点位、设备资料、已接入的外部表字段均引用真实数据目录。禁止绑定其它设备的点位，禁止把名称、连接状态等动态项冻结成固定读数。部件资料需要明确的部件上下文，不能用当前悬停部件冒充设备动作的数据。

- **范围跟随**：数值范围映射动作行程，适合门位、升降反馈等。
- **条件触发**：相等／不等／大于／大于等于／小于／小于等于。布尔和文字只使用相等／不等，比较保持类型。数值条件可设置迟滞，抑制阈值附近往返抖动。
- **条件成立不等于动作完成**：它仅驱动画面目标或运行状态，不声明 PLC 步骤已完成；不写入 PLC。
- 更换绑定后需保存才能接收对应实际输入。未保存时可使用“本页试动作”，不会影响现场及大屏。
- 坏质量、缺失、源过期时冻结；旧包不能把动作倒退，重复缓存不能伪装新采样。恢复以最新有效数据为准，不重播已错过的操作。

新配置通过 `dataItemId` 保存目录身份，运行帧 `motionInputs[actionId]` 提供实际值、质量和最后成功读取时间。新来源失效时不回退旧点位，也不取目录预览值。旧 `pointId` 配置继续兼容。

## 两个到位反馈：本轮最小联动

本轮按已确认存在的 **推料到位／退回到位** 实施，不要求先增加一大组 PLC 点位。实时联动的行程动作可选“到位反馈（两个开关量）”，从数据中心选择本设备的两个不同只读 BOOL 数据项，然后保存并同步。

| 推料到位 | 退回到位 | 状态 |
| --- | --- | --- |
| 开 | 关 | 推料端确认，显示到推料端 |
| 关 | 开 | 退回端确认，显示到退回端 |
| 关 | 关 | 等待到位反馈，保持最后显示姿态，不猜运动方向或判成功 |
| 开 | 开 | 到位反馈冲突，冻结 |
| 缺失／坏质量／过期 | 任意 | 数据无效／超时，冻结 |

仅在有效唯一到位反馈确认新端点后，沿用“过渡（秒）”做画面平滑表现；这不是现场中途位置反馈，也不以计时结束确认交接成功。重连读取当前反馈，直接对齐确认端点，不续播旧定时动画。两个都没有确认时继续等待。

不自动把物料移入炉内、不把推料到位等同于物料交接完成、不写 PLC。门开、进料中、任务号、故障或物料检测，只在现场已有且以后确需更高要求时再扩展，**不是本轮的前置条件**。

完整操作、同步边界与本轮验收入口见 [双到位开关量联动](双到位开关量联动.md)。下方为较早的数据中心动作验收记录，不冒充此次两点联动的新测试。
