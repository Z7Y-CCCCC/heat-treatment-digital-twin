# 连续点击与异常退出修复（2026-10-30）

## 对应问题与修复

1. **部件视角连续点击容易卡住。** `SelectFromWorld` 缺少设备详情分支，部件点击误走总览设备拾取，再进入 `ShowDetail`，重复重置拆解、材质、镜头和上下文。现在详情模式进入部件拾取状态机；重复选择当前部件不再重启动画、镜头或完整上下文发布，并复用经过指针、相机与几何变换校验的悬浮结果。背景点击保持当前部件，其他部件仍可选择，原生 UI 遮挡仍阻止世界拾取。
2. **Unity 异常退出后出现独立后台。** 桌面壳的 Unity 退出回调原来会主动调用 `showAdminWindow()`。现在运行就绪后 Unity 退出触发整个客户端清理，先隐藏窗口，再显示异常对话框；退出期间阻止晚到的后台显示或重启请求。受控重启和启动失败界面保留。
3. **补充退出清理。** 认证管道原来使用不能被 token 取消的同步连接等待，可能在 Unity 退出时残留线程。改为异步、可取消等待，并在取消时关闭本轮管道；销毁时线程等待最多 500ms。用户身份校验和认证消息协议没有变化。
