# 动作包合集

批量选择多个模型后，只下载一个 `动作包合集.zip`。单模型导出仍兼容原有格式。

```text
动作包合集.zip
├─ manifest.json
└─ models/
   ├─ 01-回火炉 · 09.13.00 CAD/
   │  ├─ manifest.json
   │  ├─ model.glb
   │  ├─ motion.glb
   │  └─ motion.json
   └─ 02-水冷槽 · 47.10.00 CAD/
      └─ 同类文件
```

- 导入按钮直接选择此 ZIP，无需解压。确认前可查看包内模型、动作数量及名称。
- 合集整体校验、整体提交；任一模型失败时不留下半套模型。导入为新模型，现有模型和设备绑定不覆盖。
- 重试同一次导入不会重复创建；同一请求换了文件会拒绝。
- 继续支持旧单模型 ZIP，也可同时选择多个旧包/合集包。多个独立文件仍逐个处理；每个合集内部保持原子性。
- 单合集最多 32 个模型；上传 ZIP 最大 512 MB、实际解压内容最大 480 MB，单模型文件上限保持原规则。按模型串行校验、流式计算文件摘要和写 ZIP，避免一次加载整套二进制。
- 路径、文件数量、大小、SHA-256、模型与动作匹配均校验；不接受嵌套 ZIP、额外文件或路径穿越。ZIP 中央目录在解析前限制大小和数量。
- 新接口 `POST /api/models/asset-export`（JSON：`modelIds`）；沿用 `asset-inspect`、`asset-import`，自动识别旧包与合集。导出只需原有读取权限，导入仍需模型编辑权限及原有发布历史保护。

验证入口：

```powershell
node backend/scripts/model-asset-collection-test.cjs
node tools/empty-install-model-assets-test.cjs
node tools/model-asset-transfer-ui-test.cjs
npm --prefix frontend test
node backend/scripts/run-tests.cjs
```

覆盖一次下载一个包、目录清单、旧包兼容、整包导入、重试、晚期失败回滚、非法 ZIP 及原生动作载荷保留。页面测试使用自建隔离库，需设置 Playwright/Chromium 路径；不涉及安装包安装验证。
