# 工业地面与基坑

入口：**现场编排器 → 地面与基坑**。使用平整地坪、硬边基坑和高台，不使用山地笔刷。

- 基坑/高台：设置区域标高、长宽和 X/Z；平面图可拖动区域，蓝色角点调整尺寸，方向键微调。
- 设备：填写标高或点击下沉/抬高。首次调整高度会启用“地面跟随设备”，可按模型估算占地尺寸，或手动设置长宽、净距。
- 标高以车间坐标为准，单位米；设备界面会换算产线自身高度，不需要手算坐标差。
- 自动区域跟随设备位置、朝向、缩放和标高。回到地面高度时不再生成基坑/高台；可取消自动跟随，使用多个设备共用的手动基坑。
- 后加入的区域优先；自动设备区域在手动区域之上。区域按车间边界裁切。
- 每车间最多 32 个手动区域、64 台自动跟随设备；超出自动上限时显示警告，不让场景崩溃。

## 保存与兼容

- 地面保存在 `workshops.layout_json.ground`，设备跟随参数保存在 `devices.instance_config.ground`。
- 地面独立接口检查版本、工厂归属和现场编排权限；不修改设备、PLC、模型、拆解配置或车间其他布局。
- 并发冲突保留草稿；页面切换支持保存、放弃和取消。工厂切换的“保存并切换”也包含地面。
- 普通车间编辑不会覆盖地面；项目迁移/灾备沿用原有布局与实例配置字段，无需新增数据库表。
- Unity 会替换连续地坪及内置厂房 GLB 的原地面，保留建筑、设备和导轨。编辑预览只更新地面网格，不反复导入厂房。
- Web 与 Unity 共用坐标、区域和高度验收样本。采用矩形分区网格及缓存，不引入地形编辑器引擎或新依赖。
