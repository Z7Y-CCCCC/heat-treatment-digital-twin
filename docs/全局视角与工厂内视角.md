# 视角编排

- **全局视角**：全球、国家、省、市、区县、街道、工厂建筑。开关对所有工厂生效；总开关可统一关闭或开启。开关立即保存，不需要重复到每家工厂设置。
- **工厂内视角**：全厂、车间、产线、设备、透视、拆解和部件。仍按当前工厂配置，保留拖拽、右键隐藏、恢复、撤销和发布。
- 关闭全局入口不会删除视角、组件或绑定。仍能在设计器选择关闭的视角进行编辑。
- 启动、直接链接、下钻和返回均跳过关闭的全局入口；全部关闭时进入所选／当前可见工厂的首个可见内部视角。内部默认视角被隐藏时按编排顺序选择可见项。无可见工厂时显示空状态，不反复跳转。
- 已存在的工厂内隐藏配置不修改。旧版各工厂对地图的隐藏标记不再决定入口显隐，以全局开关为准。

## 存储与权限

`settings.global_view_navigation` 是唯一全局开关；不会读取同名 `factory_settings` 覆盖。接口 `/api/view-navigation` 使用修订号防止其他窗口覆盖，修改需要“大屏设计器／修改”权限。普通大屏用户只能读取。通用设置接口不允许绕过专用保存。

发布文档只在返回运行端时投影 `metadata.runtimeHidden`，不覆盖草稿、发布快照和组件绑定。地图／街道由 WebView 路由管理，Unity 只承担工厂内部相机，避免 Esc 误入地图相机。

## 回归入口

```powershell
node backend/scripts/global-view-navigation-test.cjs
node tools/global-view-navigation-ui-test.cjs
node tools/view-hierarchy-ui-test.cjs
node tools/native-inspection-smoke-test.cjs
```

测试均使用独立目录与数据库；浏览器测试可通过 `UI_FRONTEND_DIST` 指向暂存构建，原生测试可通过 `NATIVE_INSPECTION_PLAYER` 指向暂存客户端。覆盖 128 种开关组合、跨工厂一致性、保存冲突、冷启动跳过入口、浏览器实际分类和内部拖拽／恢复、原生模型与拆解回归。
