| 预览 | 使用 WidgetRenderer 预览组件；三维、真实 PLC 和设备状态仍需目标运行环境核对。预览样例不等同于真实数据验收。 |

| 方案复用 | 本轮新增设计器“导出模板/导入模板”，保留布局、视角、组件，强制沿用目标 projectId/sceneId。有外部引用时先打开可视化重绑定，逐项选择当前工厂的设备、点位、数据源、车间、产线；全部有效才载入草稿，可取消和撤销。 |

| 项目与资产复用 | 工厂管理提供项目 ZIP 导出、校验预览和创建新工厂导入；迁移拓扑、设备/点位、模型、场景、草稿、发布记录及受支持的本地引用资产，自动重映射实体 ID、文档引用和资产路径。支持模型 glTF 外部依赖及内置模型转为可迁移资源。原工厂保留。 |
| 独立设置与共享外观 | 项目包包含受支持的工厂级配置；集团地图外观和加载画面可在导入时显式勾选应用，默认不覆盖。勾选会影响所有工厂，并发送全局配置变更通知。 |

| 模板输入校验 | JSON 格式和版本、5 MB 限制、500 组件/50 视角限制、重复/非法 ID、未来 Schema 拒绝。 |

## 仍不应宣称已完成的能力

1. 设计模板 JSON 仍仅用于画面复用；完整项目配置与本地引用资产应使用新增的项目 ZIP。外部数据库/API 账号、现场 PLC 地址和连接选项不随项目包迁移；导入的新工厂以模拟模式启动、采集关闭，需重新配置。远程 URL 的资源仍依赖远程服务。
2. 项目包和字段映射已形成跨工厂复用链路，但相似字段名或兼容类型不能证明业务含义、单位、时间口径相同；必须由工程师结合真实预览确认。不能宣称任意数据库字段全自动语义适配。全局外观默认不覆盖，显式应用前应核对其对所有工厂的影响。
3. 多组件复制已重映射被复制组件之间的内部事件目标；外部绑定保持原目标。可参数化组件模板库和模板更新传播尚未形成独立产品能力。
4. 任意行业的自定义组件插件、在线脚本编辑、第三方扩展生命周期不是当前已经完成的能力；现有低代码面向数字孪生展示和只读业务数据。
5. 已完成真实 10 分钟隔离后端耐久实测，不能据此宣称完成 72 小时。真实 Unity/WebView2 叠层、客户 PLC/外部数据库、显卡兼容、电视投屏和物理现场 72 小时连续运行仍需现场证据。本机长跑已按用户要求停止，记录为未完成；当前优先快速测试和其它主机可用性评估。

本轮已形成领域型低代码平台的“设计 → 绑定与真实预览 → 保存发布 → 项目/资产导出 → 新工厂导入 → 数据重绑定与字段确认 → 再发布”复用闭环，并补齐相关灾备覆盖。操作见 [项目迁移说明](project-bundle-migration.md)。该结论不扩大为任意行业插件平台、任意字段全自动语义映射或物理现场 72 小时验收通过。
