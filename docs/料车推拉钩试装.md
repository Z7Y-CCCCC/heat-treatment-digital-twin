# 料车中央推拉钩

在模型库选择“料车 · 10.13.00 CAD”，可查看中央滑块上的推拉钩。动作动画增加“推拉钩脱开 / 勾合”；“推料伸出 / 退回”仅移动滑块和钩头，中央导轨、导向滚轮和安装螺钉固定。

送料沿料车模型的 -X 方向，即远离回链立架的辊道开口端；对接、料盘位置和共享送料动作使用相同方向。

标准往复预览从后端 X=0.5425 m 到前端 X=-0.5425 m 再回后端，行程 1.085 m，由 1.315 m 导轨与 0.230 m 滑块外形计算。回链立架上 42 个真实链节沿原闭合轨迹循环，前进、暂停、反向退回和拖动进度均与抓钩位移一致；罩板、链轨和电机外壳不随链节转动。产线联动按对接距离计算实际演示伸出量，可以越过料车前缘继续送入设备。

产线联动在送料/取料时勾合，退链/取料伸链时脱开；滑块行程按当前设备送料距离计算，料盘的后缘与钩头工作面一起移动。此处仅演示动作时序，不向 PLC 写入控制指令。

钩头来自用户提供的 `08.05.01.05-推头.dwg` 及其 STEP 试建件，取其中一个机构单元，安装到现有 234 mm 宽中央导向机构内。880 mm 跨距的整套横梁不作为中央滑块附件。转接板、脱开角和接触面为仿真安装示意，正式安装尺寸、翻转方向、料盘结构、实际推链行程及联锁必须以现场结构和反馈为准。

原始料车 GLB 保留在 `backend/assets/models/cad_general_20261103_v1/10.13.00_料车.glb`。安装版本为 `backend/assets/models/cad_transfer_cart_101300.glb`，附件为 `backend/assets/models/attachments/push_pull_hook_08050105.glb`。其来源哈希、安装坐标和零件清单记录于附件 JSON 与模型元数据，新增节点全部位于原“推料机构”拆解总成之下。

重建：

```powershell
# 仅重新从 STEP 生成附件时需要 CadQuery；已有附件可直接执行后续三步。
python tools/export-cart-push-hook.py "路径/08.05.01.05-推头.step"
node tools/attach-cart-push-hook.mjs
node tools/align-cad-transfer-heights.mjs
node frontend/scripts/build-motion-packages.mjs --model=cad_transfer_cart_101300
node tools/model-assets.cjs --update
```

安装脚本从原始料车重新生成派生版本，可重复执行。运行软件时不需要 CadQuery 或 STEP 文件。独立的 `hook` 动作与更新后的送料动作同时进入共享动作包，现场可按真实信号另行绑定。
