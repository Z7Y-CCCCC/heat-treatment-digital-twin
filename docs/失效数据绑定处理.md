# 删除设备／点位后的大屏绑定

删除现场设备会同时删除其采集点位和**该设备专属视角的组件、绑定**。共享全厂／车间／产线组件、通用设备详情和悬停模板不会因固定绑定指向该设备就被误删。不能悄悄换成另一台设备的同名点位，也不能把原动态数据冻结成常量。

## 设备专属内容的生命周期

- 删除设备、产线或车间时，后台在同一事务中精确清理被删除设备的专属视角、静态标题、动态数值、独有悬停组件及对应绑定；清理失败则取消整个删除。
- 组件归属由明确的设备视角目标、必要的设备显隐条件或限定的设备绑定显隐确认，不凭组件名字或固定数据来源猜测。
- 共享设备列表、轮播范围和多设备显隐规则只移除被删成员；剩余对象继续使用原数据、布局和美术样式。明确设备范围删空后保持空范围，不回退成“全部设备”。
- 开着的设计器同步清理当前稿、撤销／重做历史和选择状态，保留无关的未保存编辑。后台确认记录在重新进入设计器时补同步；保存也不能恢复已经删除设备的专属内容。
- 已发布历史快照不重写、不自动发布。大屏读取发布内容时过滤已删除设备的专属内容；同 ID 后来重新创建的设备不会接管删除前的旧发布。

## 设计器如何处理

- 打开或重新进入设计器、收到配置变更、保存前重新读取设备和点位目录；只更新目录，不覆盖未保存的文字、布局和图层。
- **仍然保留的共享组件**若引用已删除或不可用的来源，显示明确提示，原设备／点位 ID 保留在数据来源选项中，便于核对；专属组件已经随设备清理，不再只留失效警告。
- 问题列表的「定位组件」使用稳定组件 ID，切到目标所在的画面／悬停模板，滚动到目标并打开其数据来源配置；悬停模板的问题不会误定位到主画布中同 ID 的组件。
- 定位目标显示独立的**红色虚线框和「问题组件」标签**，与普通选中的蓝框区分；隐藏组件也可定位，不同缩放时框线和标签仍保持可读，定位层不拦截组件操作。除了画布内滚动，也会滚动外层页面，确保目标进入屏幕可见区域。
- 重复点击会重新滚动到目标；切换设备、视角或编辑模式、删除目标、修复对应问题后清除定位状态。已取消的异步定位不会恢复过期红框或触发迟到滚动。
- 「保存草稿」允许保留不存在的引用并返回待完善警告；「保存并发布」仍要求处理这些引用，不影响当前运行的已发布版本。

## 用户处理方法

对保留的共享组件，定位后明确选择实际存在的设备和只读点位；若组件已经没有用途，可删除该组件，然后重新保存并发布。设备专属内容由设备删除生命周期自动清理，共享内容不猜测替代设备或点位。

只读限制、设备与点位归属匹配、工厂范围和草稿修订冲突仍然校验；这些错误不能作为“未完成草稿”绕过。当前设备／轮播按同角色读取的既有动态行为不因此改成固定读数。

视角侧栏不再提供重复的「编辑悬停提示内容与数据来源」按钮，悬停内容统一通过设计器顶部「悬停提示」模式编辑；视角模板选择仍保留。
