# 场景模型环形加载进度

2026-11-05。用于从园区／工厂缩略图进入原生三维总览，以及已打开大屏的模型重载。不依赖“最后一步”或固定层级序号，后续新增视角可复用。

## 行为

- 小型紫色圆环，显示当前模型和 `模型 已完成 / 总数`，不再额外堆叠“等待 Unity 确认”的重复提示。
- 配置、厂房准备、首个模型尚未完成及服务重试阶段采用不确定进度转圈；已取得真实完成数后按完成的设备模型实例数填充圆环。
- 数字来自 Unity 完成 glTF 加载、实例化并注册设备后的计数，不是传输字节百分比，也不是估算剩余时间；不会按定时器自动上涨。
- 全部模型实例完成并不等于相机／视角已准备好。仍等待同一工厂、同一目标视角的 `sceneReady` 确认，再切换到原生场景并移除圆环。没有把 HTTP 成功当成场景加载成功。
- 150ms 内完成的快切不显示提示，不设人为最短等待时间。读配置超时／Unity 不在线／导航超时则清除圆环并允许重试；离开页面中止本页等待，旧操作不能把用户拉回。
- 支持减少动态效果和窄窗口。模型重载时原生数据覆盖层也能使用同一组件；启动流程原有全屏加载页保留，不拿它替代本次进入车间的短加载提示。

## 通道

复用现有原生 `dashboard_context`，增加 `sceneLoading`：`loadId,stage,total,completed,modelName`。服务端对数量、阶段、名称长度做白名单归一化，并计算进度比例；就绪或旧版无加载状态时返回 null。只有原生角色的上下文能更新此状态，Web 端重连会收到最新上下文快照。
