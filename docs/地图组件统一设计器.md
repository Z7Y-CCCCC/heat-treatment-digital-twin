# 地图组件统一设计器

## 使用入口

**组件配置 → 大屏设计器**。全球、国家、省、市、区县与车间、产线、设备视角使用同一套图层、拖拽、内容、样式、数据来源、显隐、保存和发布流程。

“地图底图与主题”仅保留默认品牌、Logo、底图和配色设置，已删除独立的“画面组件、数据来源、画面编排”三个入口。设计器里点击地图组件不再跳到另一页。

## 旧配置

- 首次读取时，将旧标题、Logo、区域统计、区域/工厂列表、底部概览转换为普通设计器组件；保留逐层位置、隐藏状态、标题及已有 HTTP 连接/字段/刷新周期。
- 迁移本身不写工程数据库。用户保存并发布后，新版发布文档成为唯一的布局、内容、绑定来源；旧地图统计接口不再覆盖已发布的设计器绑定。
- 组件可移动、缩放、改名、换数据源、隐藏或删除；已迁移工程不会在刷新时重新生成删除的组件。
- 新增组件 ID 按场景命名，避免不同工厂相互冲突。组件上限统一为 600，为原有 500 组件工程预留迁移空间，避免归一化时丢掉尾部组件。

## 数据绑定

- 系统资料选择“地图区域数据”，直接选择当前区域指标或区域/工厂列表。数值来自实际工厂配置，不生成示例计数。
- 外部数据仍使用现有数据集、HTTP、数据库连接；与其他视角共用读取、预览、缓存、失败状态和发布流程。
- 区域数据使用“全局数据”范围，不再随机绑定/轮播一台设备；设备点位不允许使用该范围。
- 数据集“参数与匹配”支持“当前地区代码”“当前地图层级”；运行时随地图下钻传入 `regionCode`、`regionLevel`，也可按地区字段匹配记录。工厂权限范围仍由服务端决定，客户端参数不能更改工厂授权。
- “区域与工厂列表”是普通组件，支持字段、显示项和数据源配置；使用系统区域数据时保留区域下钻、工厂入口就绪检查。列表点击只对已登记的区域/工厂执行导航。

## 验证

隔离浏览器验证旧内容读取、原地拖拽编辑、保存发布、HTTP 刷新、地区数据集参数及记录匹配、区域下钻、五级地图成员关系、删除后不复活。另有多场景 ID 隔离、满 500 组件工程迁移不截断、只读设置和旧绑定保留回归。

本机四个已存场景只读回放均保留原有组件、无截断；没有写入现场数据、重启服务或验证安装包。
