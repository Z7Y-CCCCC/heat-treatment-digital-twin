## 已复现并修复

1. **心跳短断被当成退出。** 活动续期失败不再清掉大屏身份；只有服务器确认的退出、锁定或撤权更新访问状态。
2. **异常响应覆盖正常会话。** 拒绝非 JSON、缺失状态字段和不完整身份快照，不再把它们当作匿名登录状态。
3. **初次连接失败后不再重试。** 区分服务不可用与未登录，恢复后台后自动读取状态，不依赖用户重新聚焦窗口。
4. **账号同步订阅随后台页面离开而停止。** 订阅归整个 WebView 根组件管理；账户菜单不再额外维护一套重复轮询。
5. **普通用户心跳后变成主账号位置。** 后端心跳/安全设置响应补齐真实槽位；前端兼容旧响应时保留当前有效槽位，不能随意退回 `main`。
6. **修改密码后 Unity 仍持旧凭据。** 用不包含凭据的会话版本标识触发一次新授权交接；普通轮询、后台锁定和短断恢复不反复交接。
7. **首次交接失败后无法自行恢复。** 服务恢复时允许重试未成功的交接；已发出的同一身份不重复发送。
8. **页面卸载后仍发送迟到授权。** 页面卸载使旧交接作废，A 账号的迟到票据不能替换 B。
9. **断服期间刷新页面会清空 Unity/强制切登录。** 服务不可用不等于确认退出；透明层仍报告就绪，但不擅自清授权或抢到后台标签。
10. **退出登录丢掉宿主和工厂上下文。** 登录返回路径保留 `embedded/surface/factoryId`，防止原生宿主被误当成独立浏览器。
11. **激活检查遇短暂 503 直接判启动失败。** 仅对传输/服务异常做有上限的重试；持续异常仍报错，绝不跳过授权检查。无需强制授权的部署不重复提交陈旧激活表单。
12. **修改密码成功却显示红色错误，账号列表不刷新。** 成功信息改为正常状态，及时刷新其他已失效账号的显示。

另修正桌面监督测试的旧依赖桩：新增激活模块后原测试未更新，导致整组测试没进入监督逻辑；现与专门的激活测试分开验证，不访问本机真实后台。

## 复跑

```powershell
npm --prefix frontend run build
node tools/application-flow-audit.cjs --ui --native
```

`--ui` 需要 Playwright/Chromium，可用 `PLAYWRIGHT_MODULE`、`BROWSER_EXECUTABLE` 指定现有安装。`--native` 需要已构建的 Windows Unity 与后台宿主。脚本新建隔离目录与回环端口，只结束自己启动的进程。

**边界：** 没有构建或验证安装包，没有安装/卸载服务，没有重启操作者正在使用的大屏或采集服务；真实 PLC/ERP、现场长时间断网及整机断电验收未在本轮执行。通过本轮回归不等于保证所有现场条件下没有 Bug。本机应用更新仍需另行确认。
