## 原因与修正

11.14.00 升降备料台的原静态 GLB 把液压杆上端放在剪叉中轴上方。动作预览曾通过临时运动机构把它移回中轴，所以两处显示不同。

本次将油缸、活塞杆、上端销眼和对应紧固件的正确静止位置写入模型几何，同时修正可编辑 Blender 源文件和基础/精细化生成器。缸筒与活塞杆保留各自长度，通过杆件缩入缸筒形成真实重叠，不把杆件缩短或反转动作。

- 原 CAD 源坐标上端销眼：Y-up `[0, 0.545, 0]`。
- 已校准展示模型上端销眼：Y-up `[0, 0.57, 0]`。
- 首轮姿态修正保留原有 36 个 GLB 节点、25 个网格、9 个材质、15216 个三角面，以及节点名、兄弟顺序、索引和绑定路径；后续缺件补齐见下节。
- 模型管理继续直接加载原模型 GLB；没有预览姿态补丁，也没有改为加载动作模型。

## 动作兼容

源模型根节点显式声明 `liftCylinderRestPose`：

```json
{
  "schemaVersion": 1,
  "coordinateSpace": "three-y-up-local-m",
  "base": [0.48, 0.16123456790123458, 0],
  "mid": [0.0722517010692533, 0.5084708379011581, 0],
  "tip": [0, 0.57, 0]

```

这些坐标已处于该 GLB 的最终模型坐标系。动作机构读取它们以避免再次旋转已修正的几何；没有声明的旧资产继续沿用原兼容路径。非法声明明确失败，不启动时改包或迁移现场配置。

现有动作 GLB 原字节保持不变；动作 JSON 的节点、采样轨迹、时长和行程保持不变，仅更新源模型 SHA-256 关联和清单摘要。
