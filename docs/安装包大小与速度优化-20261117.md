## 修改边界

1. 主程序使用 electron-builder 原生 7z 容器，默认仍为低成本级别 1。不采用更慢的默认超高压缩。旧程序样本：7z 级别 1 压缩 58.600 秒 / 661,585,394 字节；级别 3 + BCJ2 154.294 秒 / 620,942,722 字节，收益不足以抵消耗时，因此只作为显式高级参数。
2. MySQL 不再复制应用 schema 未使用的可选 MeCab 日文全文分词字典。普通 Unicode 数据、字符集、InnoDB、数据库客户端、备份工具、其他插件和许可证保留；不改现场数据库或客户配置。
3. 独立插件保留完整离线能力与 FFmpeg 投屏能力，ZIP 使用级别 3；主包内置 ZIP 仍须与同提交的独立插件逐字节一致。
4. 冷启动测试的依赖解压和私有 MySQL 写入移到带工作区归属标记的唯一临时目录。不接受任意外部目录；保留 realpath、链接越界及文件归属检查。
5. 采集与主程序验收使用不重叠的 50 端口搜索区间，允许与迁移同时执行。仍执行全部冷启动、重启、真实测试签名激活、数据持久化、进程退出及资源不可变校验。

最终大小与整体耗时只以优化版完整构建报告为准，不把微基准或某个阶段的提速当成整体结果。默认画面模板与空现场数据规则不变。
