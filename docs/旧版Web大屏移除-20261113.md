# 旧版 Three.js 网页大屏移除记录

## 范围与安全前提

本次只移除旧的独立三维网页大屏及其程序化设备实现，不删除当前后台使用的 Three.js 模型、动作、料口、产线和画面预览。

删除前通过本机业务库只读事务核对：当前 9 台设备全部绑定真实 CAD 模型，依赖旧程序化炉子／料车的设备数为 0。未写入或重置现场库。

## 已移除

- `frontend/src/App.vue`：未挂载的旧网页三维大屏。
- `frontend/src/runtime/LayoutConfig.js`：仅由旧入口使用的布局辅助文件。
- `frontend/src/three/FurnaceModel.js`：旧程序化炉子。
- `ModelFactory.js` 内的旧程序化料车，以及缺模型／下载失败时回退旧炉子的逻辑。
- 后台内置程序化模型预览、旧预览候选项、悬停预览兜底和旧炉子专用门体／料盘节点推断。

缺少模型时保留设备身份和加载诊断，不伪造炉子／小车，也不为它绘制连接状态几何体。当前模型文件、节点路径、动作绑定及加载缓存保留。多用炉单设备完整工艺预览改用当前 CAD 料车的过程计划描述，不再隐式依赖旧程序化料车。

## 保留

Unity 客户端、透明叠加层、地图、后台、设计器、真实模型／动作包导入与预览、进出料信号配置、简易旋转小车均保留。旧网址只保留既有停用提示，不加载旧三维实现。模型类型的旧 ID 可继续作为数据标识兼容，但不再触发旧模型生成。

未删除 `output` 原有内容、模型资产、动作包、现场配置或数据库；未构建安装包、未修改固定出厂模板。GitHub 交付状态以对应提交、PR 和检查记录为准。
