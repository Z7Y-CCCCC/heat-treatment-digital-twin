# 工厂 HUD 视觉改造记录

## 当前目标与分工（2026-09-23 用户确认）

- 总目标仍是同一个原生程序内的全国／全球 → 区域 → 工厂 → 车间 → 产线 → 设备 → 部件连续浏览；设计器预览与实时大屏复用视觉模块，并以用户提供的参考图与视频为美术方向。
- 本阶段优先实现可复用的 Web HUD 美术：字体层级、面板透光、图表、指标、状态灯、地图标记和页面构图。数据绑定、运行状态及点击下钻须与实际配置一致。
- 厂房三维模型是现场定制资产；不继续把当前低模厂房打磨成所有现场通用的标准模型，也不把它的参考图级还原列为本阶段交付项。
- 用户手动查看 Unity 实际画面并进行视觉验收，反馈具体差异；开发侧做必要的构建与启动确认，然后按反馈迭代美术。不要将自动截图巡检或广泛排错作为本阶段的主要工作。
- 既有权限机制和多用户角色系统的差距仍需如实标注；视觉迭代不等于已完成权限系统或多现场数据接入。

本轮已为集团/区域页增加底部信息 Dock，展示当前范围内的登记工厂、真实定位覆盖率和本机配置层级；没有补造产量曲线或财务数据。已运行 `npm run build`，并重新启动本地服务和 Unity 客户端；用户负责检查实际画面并反馈视觉差异。

本轮地图美术已把全国/全球尺度定位锥体加上随视角变化的边缘亮度、细光柱、地面径向光晕和柔和光环；标记仍只由真实经纬度生成，高度不代表产值或设备数量。同时修正“待定位区域”无地理范围可高亮时地图被整体压暗的问题，并将全国/全球页底色收敛为中性的深灰紫。尚未填写真实经纬度时不显示虚构光柱。

地图与 Dock 改动已重新构建到 `frontend/dist`；本地服务保持原 MySQL/模拟数据配置，Unity 与 AdminHost 已重新启动，Unity 日志显示场景就绪且 6 台设备加载完成。最终光晕强弱、布局和视觉层级由用户手动验收。

共享 HUD 模块的初始加载态也已按模块形状重做：KPI 圆环、设备列表、报警时间线和趋势图各自保留布局骨架，实际数据就绪后平滑淡出；设计器预览和运行页使用同一 `WidgetRenderer.vue`。构建已通过，下一步需要在 Unity 中看实机字体、透明度与占位尺寸。

本轮继续完善共享模块标题：效率、设备、事件、趋势分别使用对应线性图标和低饱和语义色；统一加载文案改为“正在同步当前数据”，避免模拟模式下暗示 PLC 实时采集。Vite 生产构建通过，Unity 重启后由用户手动查看实际表现。

地图层级继续改为透视斜俯视相机：初次载入、全国/全球切换和区域下钻均按目标范围进行 680ms 缓动取景；用户开始拖动时立即取消自动镜头动画，保留交互控制。OrbitControls 继续约束俯仰、距离和缩放速度；Vite 生产构建通过，运行观感交用户手动验收。

## 当前可验收范围

- `/group`：全国／全球三维地图、区域下钻和当前工厂入口；原生程序首次打开从此进入，通过同一个窗口交接 Unity。地理位置未填写时明确显示“待定位”。
- 工厂登记簿：可维护其他工厂的位置元数据，全国/全球页按区域聚合，区域页显示各工厂。登记项没有运行端连接和生产指标，不会被当成本机现场。
- `/hud-preview`：现已从 `/api/config` 读取车间、产线、设备和模型库，不再使用示例排列或虚构读数；读取实际数据引擎（模拟模式会明确标注）。
- 实时位姿：新版 Unity 在预览订阅期间以约 10 Hz 推送镜头与设备世界矩阵；可勾选镜头跟随，断线/超时保留最后画面并显示暂停。仅同步整机，不伪装内部拆解动画。
- 导入厂房材质：移除按 `Hall_floor / Hall_wall / Hall_steel` 名称重写颜色、金属度、粗糙度和自发光的代码，保留 glTF 原始材质；仅设置阴影和光照探针参与。
- `/overlay`：现有工厂总览派生为 6 个完整 HUD 模块；原点位绑定、设备点击导航保留。
- 大屏设计器：同一个 `WidgetRenderer.vue` 渲染；包含模块库和独立 HUD 方案视角入口。
- 原组件仍保留。迁移只将旧工厂总览对应组件隐藏，不改车间、产线和设备视角，不自动写数据库或发布版本。
- 新版前端已构建到 `frontend/dist`，3001 端口直接提供它。

## 代码入口

- `frontend/src/runtime/factorySceneConfig.js`：Unity/glTFast 的 X 轴反射、层级变换、尺寸、镜头拟合转换。
- `frontend/src/runtime/ConfiguredFactoryScene.js`：按后台归属装配原始模型、计算设备锚点、回收过期场景资源。
- `frontend/src/runtime/nativeViewNavigation.js`：等待 Unity 匹配视角回执后才交接，同窗口显示原生画面。
- `frontend/src/views/GroupOverview.vue`：全屏地图输入区域、全国/全球切换、区域选择和工厂就绪交接。
- `frontend/src/views/admin/components/FactoryLocationSettings.vue`：在“项目与场景”维护当前现场的国家、地区、城市和经纬度；保存受既有后台认证保护。
- `frontend/src/views/admin/components/FactoryDirectorySettings.vue`：维护最多 200 项登记工厂，删除先作用于草稿；撤销可恢复，保存时校验名称、ID 与经纬度。
- `frontend/src/runtime/groupMapMarkers.js`：流线型分层渐变地图标记，只表示位置，不伪造产量编码。
- `frontend/src/runtime/nativeSurfaceBridge.js`：后台预览和原生数据层之间的同源页面交接。
- `backend/utils/dashboardDocument.js`：新模块保存/发布白名单。
- `backend/utils/sceneProjection.js`、`backend/services/wsServer.js`：投影帧校验、按需订阅、过期帧和慢连接处理。
- `frontend/src/runtime/liveSceneProjection.js`：运行镜头、设备世界矩阵转换及投影比例适配。
- `unity-client/Assets/Scripts/Runtime/FactoryRuntime.cs`：帧末捕获实际镜头和设备位姿；无预览订阅时不推送。
- `unity-client/Assets/Editor/ProjectBootstrap.cs`：每次构建检查厂房材质准备过程不改色、不修改 PBR、不克隆材质。
