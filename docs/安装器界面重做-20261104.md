# 安装器界面重做 · 2026-11-04

## 本轮交付

- 撤掉左侧步骤栏、数字编号、旧位图与多页确认流程，使用紧凑的单页安装设置。
- 保留产品图标、简短功能说明、安装路径与“更改”入口；主操作为原生圆角按钮。
- 设置、安装进度、完成、重启提示、失败页面共享同一套窗口尺寸、字体和对齐规则。
- 文件明细默认收起，不再和进度、状态互相遮挡。
- 沿用 NSIS 和 Win32 控件，不新增浏览器、Electron 安装界面或第三方 UI 插件；新增布局资源约 6.5 KiB。

设计参考的是成熟安装器的信息层级与操作收敛方式，不复制厂商素材：
[Visual Studio 官方安装流程](https://learn.microsoft.com/en-us/visualstudio/install/install-visual-studio)、
[VS Code Windows 安装说明](https://code.visualstudio.com/docs/setup/windows)、
[NSIS Modern UI 2](https://nsis.sourceforge.io/Docs/Modern%20UI%202/Readme.html)。

## 接入和边界

`desktop/display-installer.nsh` 已接入新的 `desktop/display-installer-ui.nsh` 与原生布局资源。
`allowToChangeInstallationDirectory=false` 仅移除 builder 的旧目录页；新界面仍可编辑路径、选择文件夹。
新选择的父目录自动使用产品子目录；已有安装通过程序文件标记保留原升级位置。

原有 Windows 10 1809+ / Windows 11 AMD64 限制、离线运行库准备、3010 重启提示、升级前旧采集服务迁移检查、用户数据保留均保留。
失败时给出可关闭的错误页，不进入成功页面或启动大屏；需要重启时不自动启动，也不自动重启 Windows。
采集仍是独立插件，本轮不安装、启动、停止或卸载采集服务。

## 验证

- `npm --prefix desktop run test:resources`：40 项通过，其中 9 项为安装 UI / 布局 / 边界契约。
- 原生 NSIS UI-only EXE：正常完成、失败关闭、需要重启、初始页取消均通过。
- 路径检查覆盖相对路径、磁盘根目录、Windows 目录与 System32，正常 Unicode 安装目录可继续。
- 100% / 125% / 150% / 200% 的控件边界为静态布局缩放检查，不等于四套系统 DPI 的实机安装测试。
- 本机 Node 22.13.1 的并行 test runner 出现过 V8 IPC 反序列化异常；同一组资源测试改为串行，全部运行通过，未跳过用例。

**界面重做阶段没有运行真实安装程序，没有修改现场工程、账户、数据库或正在运行的大屏。后续历史收尾阶段，Ethan 已确认构建发布新版 Release，允许隔离首启短测；实机安装仍由 Ethan 验证。发布是否成功以实际 GitHub run 和公开产物为准，不能只看源码。**

## 维护与预览

```powershell
node desktop/scripts/create-installer-ui.cjs
npm --prefix desktop run preview:installer
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/installer-preview-ui.ps1 `
  -Executable "$PWD/output/installer-preview/normal/InstallerPreview.exe" `
  -OutputDirectory "$PWD/output/installer-preview/normal" -CaptureSurface
```

其他状态：生成时使用 `--scenario=failure` / `--scenario=reboot`，验收脚本使用对应 `-Scenario`。
预览只展示实际共享的界面代码，安装段不复制软件、不写注册表、不安装运行库，启动动作只返回测试退出码。
预览脚本拒绝运行真实安装包；截图、状态报告位于 `output/installer-preview/`，不进入交付包。
布局源为 `desktop/scripts/installer-layout.cjs`；`installer-ui.bin` 是无入口点的 PE 资源容器，不是额外应用程序。
