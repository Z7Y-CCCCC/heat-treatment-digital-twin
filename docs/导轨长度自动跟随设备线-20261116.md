# 导轨长度自动跟随设备线

车间编排中，一条共享导轨的长度不再独立维护：单排跟随有设备的设备线；双排取有固定设备的较长一排，空排不额外撑长导轨。尚未摆放任何设备时，按计划中较长的设备线提供初始长度。旧式多导轨布局不猜测关联、不强制修改。

设备线把手拖动与长度输入即时更新草稿，二维和三维读取同一份长度；原有设备线“⋯”菜单可按米输入长度，自动换算已校准的场景单位。导轨把手隐藏，独立长度输入只读。自动排布预览同样呈现跟随后长度，避免预览与应用不同。图例仅作展示，不拦截设备线设置按钮；打开的设置浮层置于画布物件之上。

只改变布局尺寸，不移动、压缩或重新分配设备，不重写移动起终点、工位、PLC 或料口配置。缩短后若有已摆放设备或小车在范围外，整次变更拒绝并点名提示，不截断坐标。数字输入中间态不弹窗打断，提交后才提示无效缩短。

旧布局仅查看时不自动写库；用户修改后的草稿仍须顶部保存，沿用原有原子事务与来源版本检查。
