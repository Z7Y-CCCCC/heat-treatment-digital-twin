## 现在怎么用

1. 打开原来的「产线设备联动」，设备已经自动选好，点击 **一键演示**。
2. 自动演示使用合理的演示位置，不要求先填写现场口位、公差或循环配置，也不改保存的产线。
3. 确实需要检查保存的现场位置，再展开「高级：核对现场位置」。检查失败时可直接点击 **自动排布并演示**，无需先修好全部参数才能看动画。

没有新增正式业务页面。测试网页复用原组件和真实 CAD，仅替换隔离数据。

## 这次修正

- `0.79999999616123` 与 `0.8` 的浮点表示差不再拦截保存；由工位距离累计产生的相似尾数也能通过。真正不同的 `0.81` 仍提示具体修改为 `0.8`，而不是笼统要求“统一校准”。
- 工位、轨道坐标和间距最多显示两位小数：`17.49999968 → 17.5`、`6.999986399999998 → 7`。显示不会悄悄改写原值；缺失的坐标仍显示为空，不补成零。
- 默认演示自动选择一台可用料车和作业设备，不让保存的严格现场循环或过远位置阻止播放。
- **Web 和 Unity 的长示意送料桥均已撤掉**。原小车与机构尺寸不拉伸；推拉阶段保持原行程，设备辊道承担内部接料、送出，阶段之间不跳料。
- 三种产线模板改为按实际部件高度判断间距，避免高处排气罩将低处小车错误地推远。新模板适度留缝、最多向外微调 0.2 米，并受已知原行程限制。没有可用微调余量时锁定位置，不报浮点精度错误。
- 旧布局不自动迁移。重新应用模板需用户确认；进料面方向确实不对时仍需先调整，但普通一键演示不受影响。
