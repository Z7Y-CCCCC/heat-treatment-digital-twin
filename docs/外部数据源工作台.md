# 外部数据源工作台

入口：系统设置 → 数据连接与备份 → 外部数据源。

## 接入与配置

- 类型目录覆盖参考图全部 25 项，并增加 SQLite、OData、CSV / JSON，共 28 张本地 SVG 图片卡片，无运行时 CDN 依赖；图片来源记录见图片目录中的 provenance.json。
- 13 项可创建连接：MySQL / MariaDB、PostgreSQL、SQL Server、SQLite、HTTP / REST、OData、WebSocket、MQTT、TCP、UDP、Redis、CSV / JSON、Excel XLSX。
- 3 项使用已有设备采集通道：S7 PLC、MODBUS TCP、OPC UA，进入设备管理维护。其余 12 项明确标为“待接入”，不能创建伪可用连接。
- OData 复用只读 HTTP GET，不代表完整 OData 协议能力；其他适配器的限制见下表。
- 新建时填入对应端口、Schema 等默认值。SQL Server 新连接默认加密且校验证书。
- 左侧连接列表支持名称、地址搜索，类型筛选和 8 / 16 / 32 条分页。
- 右侧分为连接配置、认证、高级、数据预览；表单区域与列表独立限高，操作按钮始终在表单下方。
- 认证保留已有 API Key、Bearer、Basic、OAuth2 客户端凭据能力；保存后凭据以掩码返回。连接类型固定，跨适配器接入应新建连接，避免破坏原有绑定。
- 更换连接或新建类型前确认未保存修改；取消不会丢草稿。类型弹窗不因点击背景、拖选文字出界而关闭，支持关闭按钮、Escape 和焦点循环。

## 测试与预览

Excel XLSX：选择文件后可选工作表，首行作为列名，最多 1000 行数据、100 列。支持中文列名、日期、数值、布尔和公式的已保存缓存值；不启动 Excel、不运行公式/宏。导入的是副本，原文件变化需重新导入；旧 `.xls` 需先另存为 `.xlsx`。导入文件包含在整站备份及恢复中。

- 连接检查显示结果及耗时；“检查通过”不是实时在线承诺。
- 保存后可读取数据库表、视图、字段、属性，并选字段查看最多 20 条样例；不提供任意 SQL 执行入口。
- HTTP 可填写业务 GET 相对路径，读取响应字段及样例，支持现有 JSON / XML / CSV 解析。
- 未保存的新配置不借用旧连接的预览结果；失败保留表单。预览请求有版本隔离，离开或切换后忽略旧响应。
- 页面仍按原授权控制：只读账号可查看已保存数据及预览，不可新增、测试、修改或删除连接。后台接口继续做最终权限校验。
- PLC 通道仍由设备管理的 PLC 连接配置维护，不与业务数据源混在一起。

| 第一批新增 | 实际能力 / 限制 |
| --- | --- |
| WebSocket | WS/WSS 服务端主动推送，支持无认证、Basic、Bearer；不发送订阅命令 |
| MQTT | MQTT/MQTTS 只读订阅主题，QoS 0 取样；不发布、不存历史 |
| TCP | 客户端接收完整 JSON、换行帧或连接结束帧；不发送控制指令 |
| UDP | 本机 IPv4 端口接收；检查通过只说明端口可用，不代表发送端在线 |
| Redis | PING / GETRANGE 字符串键，只读且限大小；暂不支持 Hash / Stream / 集群 |
| CSV / JSON | 导入 1 MB 以内文件到私有工厂目录；单厂上限 64 MB，整站灾备含这些文件；Excel 尚未接通 |

消息连接按需取样，并非长期全量采集服务。单条网络取样限 256 KB；有超时、并发上限、短缓存和关闭连接清理。可通过设计器已有接口字段绑定链路显示数据；MQTT 主题和 Redis 键可以在读取路径处选择，其他消息与文件适配器填写 `/`。

## 验收

`tools/data-source-workspace-ui-test.cjs`：独立 SQLite、HTTP、WebSocket 及文件夹具，覆盖 28 张图片加载、类型入口、草稿保护、真实连接检查及保存、字段和样例读取、错误保留、凭据掩码、20 个连接分页、只读授权、窄窗口及弹窗交互。

`backend/scripts/data-source-transports-test.cjs`：真实环回协议通信覆盖 WebSocket、MQTT、TCP 分包、UDP、Redis、CSV/JSON 的检查、保存、字段读取、取样；限制任意路径及 URL 凭据，验证没有 MQTT 发布 / Redis 写入，并验证整站备份恢复后文件连接仍可读取。它是协议夹具验收，不等同于所有厂商服务器、TLS/ACL 配置都已现场验收。

原数据库、HTTP 回归、前端单测、整站灾备及原设置标签验收一并执行。所有夹具独立，不在正式工厂创建测试连接。

这一批有新增后台适配器，需经用户确认重启后台；单纯后续界面改动只需刷新。未完成批次：Oracle、DM8、KingbaseES、GBase 8s、MongoDB、InfluxDB、IoTDB、TDengine、openGauss、BACnet/IP、HIKVISION、DIS、Excel。必须继续实现并各自实际验证，不能仅凭图标认定完成。
