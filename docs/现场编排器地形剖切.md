# 现场编排器地形剖切

现场编排器默认对低于地面标高的基坑做随视角剖切：移除近侧挡墙，以及相机到坑底之间遮挡设备的地板片段；旋转视角后重新计算。背面边界、无关地面和高台继续显示。俯视时恢复正常地面形状。

这是仅供编辑查看的渲染效果，不改设备位置、坑尺寸、车间配置或实时大屏的 Unity 地形。`SceneRuntime.groundCutaway` 仅在编排器开启。轮廓线和射线使用同一份剖切几何，不留下透明挡面或悬空旧边线。

地面先合并同平面的网格和共线挡墙，再计算遮挡开口；静止时不重建，复杂布局限制更新频率，停止移动后补齐最终视角，替换/销毁时释放 GPU 资源和监听器。

## 验证

```powershell
npm --prefix frontend test
npm --prefix frontend run build
node tools/industrial-ground-ui-test.cjs
node tools/industrial-ground-cutaway-visual-test.cjs
```

可视化脚本只启动隔离 Vite 和无头浏览器，使用仓库中已有井式炉 CAD 模型，不访问现场数据库或暂停采集。覆盖前/后/斜向/俯视、地下视角、旋转车间、正交投影、原始配置不变和多次转动后的 GPU 资源数量。浏览器路径可通过 `PLAYWRIGHT_MODULE`、`BROWSER_EXECUTABLE` 指定。
