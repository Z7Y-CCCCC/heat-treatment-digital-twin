# CAD 产线设备统一送料高度

按用户确认，以固定备料台和料车的实际辊筒顶面 **1.250 m** 为送料面；不是轴承座最高点。8 个 CAD 设备型号在底座 Y=0、原尺寸比例下统一：多用炉、回火炉、清洗机、水冷槽、风冷台、固定备料台、升降备料台和料车。门口底沿、内部承料面齐平，门板保留约 84 mm 向下覆盖的密封搭边（风冷门按其原结构闭合到送料面）。

模型库的派生 GLB 已调整：上部进料结构平移，所需下部槽体/支承高度相应变化，底座仍落地。料车中央导轨及推拉钩作为完整层级下移 85 mm，滑块顶面不再高于承料辊，钩头实际旋转中心同步随动。固定备料台和料车辊筒原本已是 1.250 m，不改变其工作辊高度；升降台的默认交接位置同步到此高度。

动画共用该基准：80 mm 厚托盘的中心 Y=1.290 m，底面正好落在辊面。联动不再从包含轴承/螺栓的包围盒顶部估算送料高度。多用炉及水冷槽下降行程分别改为 0.80/0.85 m，保证降入液面后不穿槽底；其旋转机构、油滴、水位与升降轨迹同步适配。清洗机固定水面仍为 Y=1.20 m，升降行程仍为 0.80 m。

`shared/equipmentTransferDatum.mjs` 为展示校准参数，`tools/align-cad-transfer-heights.mjs` 只处理模型库派生文件，重复运行会校验哈希并跳过已处理文件，禁止叠加变形。初次修改前在 `output/transfer-height-backup-*` 备份，原 `cad_general_20261103_v1`、多用炉原交付目录、DWG 和 Blender 源工程未更改。需从原生成脚本重建时，重新生成派生 GLB 后运行校准，再生成全部动作包及模型清单。

这些是用户要求的统一展示尺寸，不替代制造图。实例另设比例或离地高度时，实际显示高度仍随该实例配置变化。
