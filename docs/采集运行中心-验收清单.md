# 原生采集运行中心验收（2026-10-30）

技术：C# WinForms / Windows 自带 .NET Framework。不使用 Electron、WebView2、Node.js 或浏览器内核。

- 原生 EXE 小于 512 KiB；CMD、桌面/开始菜单快捷方式直接运行该 EXE。
- 三页：状态、日志、点位；关闭不停止服务。空闲只查询 SCM 和本机 HTTP，不生成脚本或浏览器子进程。
- 点位只读，使用原后台登录、工厂/设备与实时点位接口；账号权限、Cookie 与 CSRF 沿用后台。每 5 秒刷新，切换工厂/设备清除旧结果。安装服务后开发版 Unity 也默认连接同一机器服务，避免双数据库。
- 隔离真实后端验收已确认：原生客户端无需重启，即可看到后台点位修改；不改现场数据库。
- 原生自测覆盖新鲜度、数据库、进程、多工厂、模拟模式、脱敏和 gzip JSON 导出；窗口验证覆盖日志筛选与暂停。
- 安装/启停请求 UAC；受保护日志单次授权快照，不放宽目录权限。
- 资源实测见 output/collector-center-20261030/native-ui/native-ui-result.json 和 native-idle-resources.json。
- 本机 SCM 安装、现场 PLC、无人登录重启和断电验收以实际记录为准；隔离模拟测试不能替代。

废弃 Electron 窗口源码已移除；早期截图不是最终证据。原有大屏宿主不在本次替换范围。
