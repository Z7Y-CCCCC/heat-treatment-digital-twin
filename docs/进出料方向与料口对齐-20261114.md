# 进出料方向与料口对齐

## 行为

- 已绑定的 `rollers` / `hot_rollers` 动作根据进出料方向运行。方向按辊筒上表面实际输送方向计算，包含动作包四元数轴、glTF 坐标转换、设备朝向及父级缩放，不是对所有模型使用同一个正负号。
- 反转累计动画相位，不跳回动作起点；方向冲突、数据过期或连接中断时辊筒不再继续转动。无关风机动作不受影响。
- 简易工位停车使用已选固定设备的实际料口与小车料口偏心量，投影到现有导轨。只修正导轨方向位置，保留高度、轨道平面、固定设备布局及已保存工位编号。
- 旋转车只旋转上平台；其简模辊筒方向与送料／取料一致。单向车背面交接门禁保留。
- 沿用已有料口和点位绑定，不增加距离、加速度或现场测量表单。

## 验证

- `ConveyorDockingValidation.Run`：77 项真实 Unity 变换断言，覆盖双方向、反转相位连续、设备旋转、镜像和非均匀缩放、数据过期、风机隔离、料口偏心及布局更新。
- 简易工位移动 11 项、连续物料交接 21 项、旋转小车 25 项回归通过，共 134 项。
- 隔离 S7 模拟器 → 后端实际采集 → Unity 客户端：单向车与正面四台设备完成 8 次送料／取料；检查原生辊筒四元数变化、正反方向及两料口横向误差。
- 本机当前客户端已同步并通过正常 CMD 入口重启、场景就绪；现场布局和实例配置只读复核未变。

现场库、原始导出、令牌、录像、客户端二进制、日志及验收输出仅保留本机忽略目录，不提交 Git。没有构建安装包或改动出厂模板。
