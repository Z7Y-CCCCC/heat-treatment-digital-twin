# 生产部件实时运动

在仓库根目录运行 `node tools/multipurpose-motion-demo.cjs`，启动独立模拟数据库和已构建的 Unity Windows 客户端，并聚焦多用炉；前炉门、中门循环开关。关闭该 Unity 窗口会停止演示后端；加 `--check` 会在验证开、关信号与场景加载后自动退出。演示写入 `output/multipurpose-motion-demo-*`，不连接现场 PLC。

如果宿主重复发送已用过或已过期的一次性登录凭据，Unity 会忽略重复消息；对过期消息，只有重新向后端确认当前大屏会话仍有查看和启动权限后，才保留已加载场景。真正退出账户后仍会停止授权显示。`--check` 同时覆盖重复凭据、失效凭据和真实退出账户三种情况。

实时数据链路为：PLC 只读采集 → 后端 WebSocket → 当前设备的模型部位绑定 → Unity 实时大屏。相同模型可以复用动作定义，各设备使用自己的点位值。运动绑定与手工拆解布局分别配置。

在后台“模型库”打开设备模型，进入“部位绑定”，选择右侧解析的部件节点。可使用炉门升降、阀门开关、有料显示三个示例，再填写点位字段并保存部位绑定。示例只填表，不会自动保存或猜测现场 PLC 地址。

| 现场信号 | 动作 | 输入 | 输出示例 | 全行程时间 |
| --- | --- | --- | --- | --- |
| 炉门开状态 BOOL | 沿 Y 轴平移 | 0–1 | 0–1.5（模型局部坐标） | 3 秒 |
| 阀门开状态 BOOL | 按数值转角 | 0–1 | 0–90 度 | 1 秒 |
| 有料 BOOL | 按布尔显示 | false / true | 隐藏 / 显示工件节点 | 不适用 |
| 炉门实际开度 | 平移或转角 | 按 PLC 量程，例如 0–100 | 按模型实测行程 | 0，直接跟随 |

点位字段与该设备点位的 `value_role` 一致，数据分组与点位分类一致。请先在点位监视确认值和质量，再在模型绑定里试验。BOOL 的 false=0、true=1；信号极性相反的平移/转角交换输出最小与最大，显示动作可选择“反向”。行程和轴向需按模型校准，不能直接把示例的 1.5 当成现场米数；阀门应选择围绕正确枢轴导出的旋转节点。

“全行程时间”是输出最小到最大的运动时间，范围 0–60 秒。运动中反向从当前位置返回，重复采样不会重新开始。第一次获取有效数据直接对齐当前状态，避免启动时播放虚构的动作。旧绑定未设置时间时保持直接跟随。

只有开关状态或到位信号时，模型的中间运动是示意。如果 PLC 仅在完全打开后置位“开到位”，动画也只能在到位信号变化后响应，不能据此还原真实开门起始时刻。需要同步全过程，应接入开门中/关门中及到位反馈，或者连续行程值；请提供准确的点位语义后再配置。不要把“有料”直接解释成料盘正在进出；连续移动同样需要位置或过程反馈。

绑定点质量不是 good、设备离线或数据缺失时，停止该部件运动并保持最后姿态，等待新的有效样本。其他无关点异常不阻止该部件。生产 PLC 地址、账号和连接方式需要现场点位表，不能使用演示地址替代。
