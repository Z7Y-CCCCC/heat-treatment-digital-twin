# 厂商激活码工具

双击项目根目录 **厂商激活码工具.cmd**。使用已有 Node.js（优先复用项目自带运行时）和系统浏览器；没有 Electron、npm 依赖、数据库或联网签发服务。关闭命令窗口即停止工具。它只监听随机回环端口，每次启动有独立访问令牌。

## 厂商操作

1. 首次点击“初始化密钥”，以后始终沿用这对密钥，不允许覆盖重建。
2. 离线备份私钥。默认数据目录：`%LOCALAPPDATA%\HeatTreatmentDigitalTwinIssuer`，包含公私钥及 `issued` 签发记录。若旧工具目录已有密钥，会继续使用旧目录，不另建身份。可用 `LICENSE_ISSUER_DATA_DIR` 指定受控目录。
3. 粘贴客户指纹，填写客户和有效期（也可选永久），点击“生成激活码”。
4. 把激活码或 TXT 发给客户。JSON 也保留在 `issued`，兼容原许可证导入。不要把私钥、工具或整个数据目录发给客户。

## 打包

`生成安装包.ps1` 的资源准备步骤从上面的签发目录读取公钥，将 **公钥** 放入安装包 `resources/licensing/license-public-key.pem`。需要指定其他签发身份时，设置 `LICENSE_ISSUER_PUBLIC_KEY_FILE`。打包缺公钥会报错，不再静默生成免激活版本。

不要在签发过客户许可证后随意更换公钥；否则旧许可证将无法通过新版本校验。私钥丢失不能用公钥恢复，应从厂商备份恢复。工具不会把私钥通过 HTTP 返回给浏览器。

## 客户操作

新电脑安装后：启动 → 加载页显示本机指纹 → 复制给厂商 → 粘贴厂商激活码 → 激活并继续 → 原有首次设置后台密码/登录流程。有效授权会持久保留，普通退出、服务重启和升级不要求重新输入。

后台“授权与版本”用于查看授权、激活记录及旧激活码；管理员通过“续期 / 更新授权”输入新码，保留旧记录。无效新码不会覆盖有效授权。不提供“撤销激活/删除许可证”按钮。

采集服务拥有授权文件；桌面程序通过受限的本机激活接口提交激活码，普通 Windows 用户不需要服务数据目录写权限。远程展示客户端复用服务端授权，需在采集服务器本机激活，不把服务器指纹误当成另一台展示电脑的指纹。

## 技术与边界

- `HTA1` 激活码是签名许可证的文本封装，不是随机短口令；可直接复制粘贴，也支持 TXT 传递。
- Ed25519 私钥签发、公钥验签。新码使用操作系统机器标识的散列绑定，复制应用/数据目录到另一台正常安装系统的电脑不能直接使用。旧版签名/安装锚点许可证仍兼容。
- 系统重装、机器克隆或更换电脑应重新核验并签发；不是对本机管理员修改程序的绝对防护。
- 不连接厂商服务器，不做在线心跳。永久授权可离线使用；限期授权应提前续期，过期时业务接口按授权策略拒绝访问。本次没有增加“断网就退出大屏/停止已有采集”的逻辑。
- 许可证和激活记录在同一原子文件中提交，并保留备用文件；失败签发/校验不写入历史。旧版此前没有记录过、已经丢失的激活码不能追溯恢复。
