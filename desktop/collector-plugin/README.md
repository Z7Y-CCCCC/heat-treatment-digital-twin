# 数据采集插件

可选 Windows 服务。开机采集，无需登录桌面；关闭大屏或运行中心不停止采集。不包含 Unity / Electron 展示程序。

产品分为两部分：大屏＋后台管理属于展示程序；本包仅包含原生采集运行中心、采集服务、数据/API 与存储运行时。**本包不包含大屏/后台网页构建，也不会启动它们**。展示程序使用自己的界面资源，连接本服务的数据接口；退出展示程序只关闭它自己的连接，不停止服务。两端共享同一份工程配置和点位，不应创建两套相互漂移的现场工程。

解压到本机，保存并退出大屏，运行“安装采集插件.cmd”，或从解压包的“采集运行中心.cmd”点击安装服务。安装器校验文件后请求管理员权限，复制到独立目录，注册服务。首次导入当前用户的大屏数据；已有机器级采集数据继续使用，不覆盖。原数据保留。缺少完整资源、端口占用、数据库仍活动时明确拒绝安装，不强行结束其他程序。

生产服务保留正式授权校验；厂商工具只在签发方使用，私钥和已签发记录不属于本包。可用 `安装采集服务.ps1 -InstallRoot <本包绝对路径> -CheckOnly` 进行不需要管理员权限的只读预检。

服务数据：`%PROGRAMDATA%\HeatTreatmentDigitalTwin\collector`。服务程序：`%ProgramFiles%\HeatTreatmentCollectorPlugin`。未明确选择“独立展示”的大屏重新启动后会发现本机服务；若已选择独立展示，请在“部署与连接”明确改为连接独立采集服务。后台配置与采集共用同一个服务及数据库，不产生第二套现场工程。服务停止时明确报离线，不回退到其他数据库或模拟数据。

卸载：以管理员身份运行插件安装目录的 `安装采集服务.ps1 -Uninstall`。只移除服务，保留数据、授权和连接配置；不会自动切回旧的用户库。需要恢复纯展示时，先导出整站备份，在“部署与连接”明确选择本机展示，再导入备份。

独立插件携带自己的 Node/API、配置库和 MySQL 运行时，不依赖大屏程序目录，允许独立维护。外部 HTTP/HTTPS、数据库等数据源由后台管理配置；不安装本插件也可运行大屏及其接口控件。
