# CAD 设备 GLB 模型

7 份独立 GLB，单位米、Y 轴向上，全部材质内置，无外部贴图依赖。材质沿用现有 V6 工业设备模型。
按提供的二维总图、剖视图及标注尺寸重建，细节采用实体网格。图纸没有给出的尺寸按视图比例推定，不冒充实测数据；本文件不替代制造图。
底部为放置原点；水冷槽的地坪高于模型底部 383 mm，清洗机总图底座有 150 mm 安装深度。
模型保留门、传动、滚床、管路等功能分组，但没有虚构 PLC 绑定或动画。

## 版本选择

- 风冷台：选用 HT 升降门版本；不是同文件中的 XQ 简版。
- 固定备料台：两份重复布置是同一台设备，不合并成双台。6 对滚轮，轴距 280 mm。
- 升降备料台：以总图明确文字 1045 mm 为升降台面标高，滚轮组件到工作高度 1200 mm；不采用采购页旧注 1050。5 对滚轮，轴距 320 mm。
- 回火炉：选用 600KG／09.13.00 原总图；不混用 4424 mm 加高或 XQ 版本。炉内滚道、加热元件和循环机构依剖视图重建，未标注零件尺寸按视图比例推定。
- 料车：选用 600 料车／10.13.00；不采用同文件中 1.2T／10.02.00 版本。未标注链架细节按视图比例重建。
- 清洗机：选用 17.07.00 高提升版本（MAX 4107），保留双侧水箱、循环管路及驱动；不是照片 V7 外形。 2026-11-04 修复：补回 K 向与侧视图存在的中央下部薄壁壳体；前板宽 1200 mm、折面顶部标高 1121 mm，门槛 1295 mm。板厚、折面深度及未注尺寸为展示推定。 2026-11-04 修复：补回 K 向与侧视图存在的中央下部薄壁壳体；前板宽 1200 mm、折面顶部标高 1121 mm，门槛 1295 mm。板厚、折面深度及未注尺寸为展示推定。
- 水冷槽：完整显示下部槽体；安装时地坪基准比模型底部高 383 mm。液面为静态可移除组件。

`sources/`：独立可编辑 Blender 工程；`previews/`：正反面渲染；`metadata/`：图纸哈希、标注尺寸、分组、回读校验。
原始 DWG 的 SHA-256 全部复核未变，也没有写入当前运行工程或替换旧模型。
