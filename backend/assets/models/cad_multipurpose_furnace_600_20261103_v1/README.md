# 600 普通多用炉 · 08.20.00

文件：`08.20.00_600普通多用炉.glb`；8.28 MB；161,148 个三角形。
独立 GLB，米制、Y 轴向上，内置 PBR 材质；延用现有工业设备灰白箱体、深色框架、金属、青色电机、绿色管路。
放置原点在淬火槽底；图示地坪在模型底部以上 0.400 m，工作标高 1.230 m 对应模型底部起 1.630 m。

## 结构

- 前室与下部一体淬火槽、双侧搅拌机构、单套升降滚床及导柱。虚线所示低位是同一滚床的另一位置，没有建成第二套。
- 前门及侧面回链机构、横向传动轴、带槽轮盘、链节销轴、减速机、配重与限位开关。
- 中间隔热门、提升油缸和门架；后部加热室、拱形外壳与内衬、拱砖、辊道和辐射管。
- 顶部循环风机、轴与叶轮，前置斜面抽风罩与排风管，后端推杆及管路、阀门、热电偶。
- 搅拌器人孔法兰、6 个加热／检修口、检修盖与紧固件、顶部服务面板、平台及爬梯。
